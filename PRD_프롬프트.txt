01. 홈 둘러보기

1. 기능 정리

프롬프트:
내 담당은 차를 찾고 빌리는 쪽이야. '홈 둘러보기'에서 사용자가 할 일을 정리해봤어.
이걸 기준으로 이 화면의 PRD를 작성해줘. 화면에 뭐가 나오는지, 뭘 누르면 어떻게 되는지 알 수 있게 써줘.

이 화면에서 필요한 건 이거야.
- 로그인 안 해도 차가 어떤 식으로 보이는지 먼저 볼 수 있으면 좋겠어.
- 차 목록을 둘러볼 수 있고 지금 보고 있는 조건을 알 수 있으면 돼.
- 보여줄 차가 없어도 빈 화면처럼 보이지 않았으면 좋겠어.

원래 있는 화면 모양이랑 공통으로 쓰는 부분은 그대로 써줘.
다른 담당 화면으로 넘어가는 연결은 나중에 같이 맞출게.

2. PRD

화면: 홈 둘러보기
보여줄 내용: 로그인 안 해도 차가 어떤 식으로 보이는지 먼저 볼 수 있으면 좋겠다.
주요 기능: 차 목록을 둘러볼 수 있고 지금 보고 있는 조건을 알 수 있으면 된다.
잘못됐을 때: 보여줄 차가 없어도 빈 화면처럼 보이지 않았으면 좋겠다.

정한 것
- 로그인하지 않아도 차는 구경할 수 있으면 한다. 예약하려고 할 때는 로그인과 필요한 확인을 먼저 하도록 안내하면 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.

프롬프트:
