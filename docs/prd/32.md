# 32. AI 외관 등급

대상: AI 외관 등급

1) 확인하거나 적을 내용
올린 사진으로 나온 등급과 설명을 볼 수 있으면 된다.

2) 처리할 일
결과를 다시 불러오고 사진을 바꾸면 다시 확인할 수 있으면 좋겠다.

3) 멈추고 알려야 할 부분
현재는 개발용 결과라 실제 판정이 아니라는 걸 표시하고 싶다.

4) 관리할 때 지킬 기준
사진으로 확인한 등급과 그 이유를 보고 싶다. 지금은 연습용 결과라면 실제 차량 상태를 확인한 결과로 오해하지 않게 표시해야 한다.
