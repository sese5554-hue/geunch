# 47. 호스트 마이페이지

화면: 호스트 마이페이지
보여줄 내용: 호스트인 내 정보와 인증 상태, 차량 관리 메뉴를 보고 싶다.
주요 기능: 계정 정보를 바꾼 결과가 이 화면에도 맞게 나오면 된다.
잘못됐을 때: 로그아웃하면 내 정보가 계속 보이지 않았으면 좋겠다.

정한 것
- 내 정보와 차량 관리 메뉴를 보고 싶다. 로그아웃하면 내 이름과 전화번호가 남지 않고, 다른 사람이 로그인했을 때 내 정보가 보이면 안 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
