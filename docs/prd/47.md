# 47. 호스트 마이페이지

기능 이름 | 호스트 마이페이지
볼 내용 | 호스트인 내 정보와 인증 상태, 차량 관리 메뉴를 보고 싶다.
할 수 있는 일 | 계정 정보를 바꾼 결과가 이 화면에도 맞게 나오면 된다.
안내할 내용 | 로그아웃하면 내 정보가 계속 보이지 않았으면 좋겠다.
지킬 조건 | 내 정보와 차량 관리 메뉴를 보고 싶다. 로그아웃하면 내 이름과 전화번호가 남지 않고, 다른 사람이 로그인했을 때 내 정보가 보이면 안 된다.
