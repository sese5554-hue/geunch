# 34. 호스트 예약 목록

대상: 호스트 예약 목록

1) 확인하거나 적을 내용
내 차에 들어온 예약을 날짜와 상태별로 보고 싶다.

2) 처리할 일
승인하거나 거절한 결과가 목록에도 반영되면 좋겠다.

3) 멈추고 알려야 할 부분
예약이 없거나 목록을 못 읽었을 때 구분해서 알려주면 된다.

4) 관리할 때 지킬 기준
내 차에 들어온 예약만 보고 싶다. 승인하거나 거절한 다음 목록에도 바뀐 상태가 나오고, 아무 예약도 없는 것과 불러오기 실패를 구별했으면 한다.
