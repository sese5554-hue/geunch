# 35. 예약 요청 상세 및 관리

대상: 예약 요청 상세 및 관리

1) 확인하거나 적을 내용
누가 언제 내 차를 빌리려는지 금액이랑 같이 보고 싶다.

2) 처리할 일
승인하거나 거절하면 처리 결과가 저장돼야 한다.

3) 멈추고 알려야 할 부분
이미 처리된 예약이나 내 차 예약이 아닌 건 바꾸지 못하게 하고 싶다.

4) 관리할 때 지킬 기준
내 차에 들어온 예약만 승인하거나 거절할 수 있어야 한다. 이미 처리한 예약을 다시 누르면 현재 상태를 알려주고 다른 사람 예약은 바꾸지 못하게 하면 된다.
