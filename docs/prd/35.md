# 35. 예약 요청 상세 및 관리

화면: 예약 요청 상세 및 관리
보여줄 내용: 누가 언제 내 차를 빌리려는지 금액이랑 같이 보고 싶다.
주요 기능: 승인하거나 거절하면 처리 결과가 저장돼야 한다.
잘못됐을 때: 이미 처리된 예약이나 내 차 예약이 아닌 건 바꾸지 못하게 하고 싶다.

정한 것
- 내 차에 들어온 예약만 승인하거나 거절할 수 있어야 한다. 이미 처리한 예약을 다시 누르면 현재 상태를 알려주고 다른 사람 예약은 바꾸지 못하게 하면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
