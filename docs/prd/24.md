# 24. 이용 후기 작성

화면: 이용 후기 작성
보여줄 내용: 별점과 후기 내용을 입력할 수 있으면 된다.
주요 기능: 이용이 끝난 예약의 상대방에게 후기를 한 번 남기고 싶다.
잘못됐을 때: 아직 안 끝난 예약이거나 이미 썼으면 이유를 알려주면 좋겠다.

정한 것
- 이용을 마친 내 예약에만 후기를 쓸 수 있으면 한다. 같은 이용에 두 번 쓰지 못하게 하고, 이미 썼으면 작성 완료라고 보여주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
