# 24. 이용 후기 작성

기능 이름 | 이용 후기 작성
볼 내용 | 별점과 후기 내용을 입력할 수 있으면 된다.
할 수 있는 일 | 이용이 끝난 예약의 상대방에게 후기를 한 번 남기고 싶다.
안내할 내용 | 아직 안 끝난 예약이거나 이미 썼으면 이유를 알려주면 좋겠다.
지킬 조건 | 이용을 마친 내 예약에만 후기를 쓸 수 있으면 한다. 같은 이용에 두 번 쓰지 못하게 하고, 이미 썼으면 작성 완료라고 보여주면 된다.
