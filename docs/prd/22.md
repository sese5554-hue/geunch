# 22. 외관 및 계기판 비교

화면: 외관 및 계기판 비교
보여줄 내용: 인수 때랑 반납 때 사진, 주행거리를 나란히 보고 싶다.
주요 기능: 양쪽 사람이 확인했는지 알 수 있고 이의가 있으면 남길 수 있으면 좋겠다.
잘못됐을 때: 내가 확인한 것과 상대도 확인한 걸 구분하고 실제 파손 판정처럼 단정하지 않으면 된다.

정한 것
- 내가 확인했는지와 상대방이 확인했는지를 따로 볼 수 있으면 한다. 양쪽 확인이 끝나지 않았거나 이의가 남아 있으면 정산을 끝내지 않았으면 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
