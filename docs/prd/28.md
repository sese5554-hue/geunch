# 28. 차량 기본 정보 입력

대상: 차량 기본 정보 입력

1) 확인하거나 적을 내용
차 이름, 연식, 번호랑 지역을 입력할 수 있으면 된다.

2) 처리할 일
먼저 기본 내용만 저장해서 차를 등록해두고 나머지는 나중에 넣고 싶다.

3) 멈추고 알려야 할 부분
빠진 항목이나 이미 있는 차량번호는 알려주면 된다.

4) 관리할 때 지킬 기준
기본 정보만 저장한 차는 아직 검색에 공개하지 않았으면 한다. 차량번호가 이미 등록돼 있거나 꼭 적어야 할 내용을 빼먹었으면 알려주면 된다.
