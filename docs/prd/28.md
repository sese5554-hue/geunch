# 28. 차량 기본 정보 입력

화면: 차량 기본 정보 입력
보여줄 내용: 차 이름, 연식, 번호랑 지역을 입력할 수 있으면 된다.
주요 기능: 먼저 기본 내용만 저장해서 차를 등록해두고 나머지는 나중에 넣고 싶다.
잘못됐을 때: 빠진 항목이나 이미 있는 차량번호는 알려주면 된다.

정한 것
- 기본 정보만 저장한 차는 아직 검색에 공개하지 않았으면 한다. 차량번호가 이미 등록돼 있거나 꼭 적어야 할 내용을 빼먹었으면 알려주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
