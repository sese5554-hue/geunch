# 43. 1:1 문의 접수

기능 이름 | 1:1 문의 접수
볼 내용 | 문의 종류, 제목, 내용을 적고 사진도 붙일 수 있으면 된다.
할 수 있는 일 | 접수를 누르면 한 번만 저장되고 접수됐는지 알려주면 좋겠다.
안내할 내용 | 제목이 없거나 사진 올리기 실패면 적은 내용은 남겨두고 다시 할 수 있으면 된다.
지킬 조건 | 제목과 내용을 적고 사진을 붙여서 문의하고 싶다. 사진이나 접수에 문제가 생겨도 적은 내용은 남아야 하고, 다시 눌러도 같은 문의가 두 개 생기지 않았으면 한다.
