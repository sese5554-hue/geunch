# 43. 1:1 문의 접수

화면: 1:1 문의 접수
보여줄 내용: 문의 종류, 제목, 내용을 적고 사진도 붙일 수 있으면 된다.
주요 기능: 접수를 누르면 한 번만 저장되고 접수됐는지 알려주면 좋겠다.
잘못됐을 때: 제목이 없거나 사진 올리기 실패면 적은 내용은 남겨두고 다시 할 수 있으면 된다.

정한 것
- 제목과 내용을 적고 사진을 붙여서 문의하고 싶다. 사진이나 접수에 문제가 생겨도 적은 내용은 남아야 하고, 다시 눌러도 같은 문의가 두 개 생기지 않았으면 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
