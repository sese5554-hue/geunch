# 16. 결제 수단 및 예약 요청

화면: 결제 수단 및 예약 요청
보여줄 내용: 쓸 결제수단이랑 예약할 금액을 확인할 수 있으면 된다.
주요 기능: 예약을 누르면 요청이 한 번만 들어가고 아직 승인 대기라는 걸 알려주고 싶다.
잘못됐을 때: 결제수단이 없거나 금액이 달라졌으면 이유를 보여주고 다시 확인하게 하고 싶다.

정한 것
- 버튼을 두 번 누르거나 기다리다 다시 눌러도 같은 예약이 두 개 생기면 안 된다. 금액이 달라졌으면 다시 확인하게 하고 아직 승인 전이라는 안내가 필요하다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
