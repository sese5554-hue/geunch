# 16. 결제 수단 및 예약 요청

결제 수단 및 예약 요청

어디에서 쓰는 화면인지
쓸 결제수단이랑 예약할 금액을 확인할 수 있으면 된다.

이 화면에서 할 일
예약을 누르면 요청이 한 번만 들어가고 아직 승인 대기라는 걸 알려주고 싶다.

결과가 안 나올 때
결제수단이 없거나 금액이 달라졌으면 이유를 보여주고 다시 확인하게 하고 싶다.

화면을 쓰는 기준
버튼을 두 번 누르거나 기다리다 다시 눌러도 같은 예약이 두 개 생기면 안 된다. 금액이 달라졌으면 다시 확인하게 하고 아직 승인 전이라는 안내가 필요하다.
