# 09. 지도에서 차량 찾기

지도에서 차량 찾기

어디에서 쓰는 화면인지
지도 위에 차 위치랑 가격이 보이면 찾기 편할 것 같다.

이 화면에서 할 일
지도를 옮기면 그쪽 차를 찾아주고 차를 누르면 어떤 차인지 보여주면 좋겠다.

결과가 안 나올 때
위치를 허용하지 않아도 지역을 골라 찾을 수 있으면 된다.

화면을 쓰는 기준
지도를 옮기면 지금 지도에 보이는 곳을 기준으로 차를 찾아줬으면 한다. 위치 사용을 거절해도 직접 동네를 골라 찾을 수 있어야 한다.
