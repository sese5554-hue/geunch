# 09. 지도에서 차량 찾기

화면: 지도에서 차량 찾기
보여줄 내용: 지도 위에 차 위치랑 가격이 보이면 찾기 편할 것 같다.
주요 기능: 지도를 옮기면 그쪽 차를 찾아주고 차를 누르면 어떤 차인지 보여주면 좋겠다.
잘못됐을 때: 위치를 허용하지 않아도 지역을 골라 찾을 수 있으면 된다.

정한 것
- 지도를 옮기면 지금 지도에 보이는 곳을 기준으로 차를 찾아줬으면 한다. 위치 사용을 거절해도 직접 동네를 골라 찾을 수 있어야 한다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
