# 40. 결제수단 관리

화면: 결제수단 관리
보여줄 내용: 등록한 결제수단과 기본으로 쓸 것을 구분해서 보고 싶다.
주요 기능: 기본 결제수단을 바꾸거나 필요 없는 걸 지울 수 있으면 좋겠다.
잘못됐을 때: 등록한 게 없으면 안내하고 삭제 실패 시 없어진 것처럼 보이지 않으면 된다.

정한 것
- 기본으로 쓸 결제수단은 하나만 고를 수 있으면 한다. 지우기에 실패했으면 목록에서 사라진 것처럼 보이지 않고 다시 시도할 수 있어야 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
