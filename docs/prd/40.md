# 40. 결제수단 관리

기능 이름 | 결제수단 관리
볼 내용 | 등록한 결제수단과 기본으로 쓸 것을 구분해서 보고 싶다.
할 수 있는 일 | 기본 결제수단을 바꾸거나 필요 없는 걸 지울 수 있으면 좋겠다.
안내할 내용 | 등록한 게 없으면 안내하고 삭제 실패 시 없어진 것처럼 보이지 않으면 된다.
지킬 조건 | 기본으로 쓸 결제수단은 하나만 고를 수 있으면 한다. 지우기에 실패했으면 목록에서 사라진 것처럼 보이지 않고 다시 시도할 수 있어야 한다.
