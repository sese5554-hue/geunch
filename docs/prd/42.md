# 42. 고객센터

화면: 고객센터
보여줄 내용: 자주 묻는 질문이랑 답을 찾아볼 수 있으면 좋겠다.
주요 기능: 궁금한 항목의 내용을 읽을 수 있으면 된다.
잘못됐을 때: 아무 항목도 못 읽었으면 잠시 후 다시 보라고 안내하고 싶다.

정한 것
- 질문을 누르면 그에 맞는 답변을 읽을 수 있으면 한다. 내용을 못 불러오면 없는 것처럼 두지 말고 다시 볼 수 있게 안내해주면 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
