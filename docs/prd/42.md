# 42. 고객센터

기능 이름 | 고객센터
볼 내용 | 자주 묻는 질문이랑 답을 찾아볼 수 있으면 좋겠다.
할 수 있는 일 | 궁금한 항목의 내용을 읽을 수 있으면 된다.
안내할 내용 | 아무 항목도 못 읽었으면 잠시 후 다시 보라고 안내하고 싶다.
지킬 조건 | 질문을 누르면 그에 맞는 답변을 읽을 수 있으면 한다. 내용을 못 불러오면 없는 것처럼 두지 말고 다시 볼 수 있게 안내해주면 된다.
