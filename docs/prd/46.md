# 46. 결제수단 추가

화면: 결제수단 추가
보여줄 내용: 새 결제수단을 등록하는 데 필요한 입력과 안내가 있으면 된다.
주요 기능: 등록이 끝나면 내 목록에서 확인하고 싶다.
잘못됐을 때: 현재는 개발용 등록이라는 걸 알리고 같은 등록이 두 번 되지 않으면 좋겠다.

정한 것
- 카드번호를 앱에 그대로 남겨두지 않고 결제수단을 등록하고 싶다. 같은 등록을 두 번 하지 않게 하고, 지금은 연습용 등록이면 그 표시가 필요하다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
