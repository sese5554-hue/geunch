# 46. 결제수단 추가

기능 이름 | 결제수단 추가
볼 내용 | 새 결제수단을 등록하는 데 필요한 입력과 안내가 있으면 된다.
할 수 있는 일 | 등록이 끝나면 내 목록에서 확인하고 싶다.
안내할 내용 | 현재는 개발용 등록이라는 걸 알리고 같은 등록이 두 번 되지 않으면 좋겠다.
지킬 조건 | 카드번호를 앱에 그대로 남겨두지 않고 결제수단을 등록하고 싶다. 같은 등록을 두 번 하지 않게 하고, 지금은 연습용 등록이면 그 표시가 필요하다.
