# 11. 검색 필터

화면: 검색 필터
보여줄 내용: 차 크기나 연료, 가격 같은 검색 조건을 고를 수 있으면 좋겠다.
주요 기능: 조건을 적용하면 고른 값이 검색에 반영되고 초기화도 되면 된다.
잘못됐을 때: 가격 범위를 거꾸로 넣으면 바로 알려주면 좋겠다.

정한 것
- 초기화를 누르면 화면에 보이는 선택과 실제로 찾는 조건이 함께 지워졌으면 한다. 최소 금액이 최대 금액보다 크면 알려주면 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
