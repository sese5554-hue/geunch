# 11. 검색 필터

검색 필터

어디에서 쓰는 화면인지
차 크기나 연료, 가격 같은 검색 조건을 고를 수 있으면 좋겠다.

이 화면에서 할 일
조건을 적용하면 고른 값이 검색에 반영되고 초기화도 되면 된다.

결과가 안 나올 때
가격 범위를 거꾸로 넣으면 바로 알려주면 좋겠다.

화면을 쓰는 기준
초기화를 누르면 화면에 보이는 선택과 실제로 찾는 조건이 함께 지워졌으면 한다. 최소 금액이 최대 금액보다 크면 알려주면 된다.
