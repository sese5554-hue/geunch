# 05. 본인 확인

화면: 본인 확인

필요한 내용
본인 확인에 필요한 이름 같은 정보를 입력할 수 있으면 된다.

버튼을 누르면
확인이 끝났는지 화면에서 알 수 있고 다시 열어도 결과가 남으면 좋겠다.

빠뜨리거나 틀렸을 때
지금은 개발용 확인이라는 걸 보여주고 실패하면 다시 해볼 수 있게 하고 싶다.

꼭 맞출 부분
확인됐다는 글자만 바뀌는 게 아니라 다시 들어와도 확인 결과가 남았으면 한다. 연습용 확인이라면 실제로 본인 확인을 마쳤다고 오해하지 않게 표시하면 된다.
