# 05. 본인 확인

화면: 본인 확인
보여줄 내용: 본인 확인에 필요한 이름 같은 정보를 입력할 수 있으면 된다.
주요 기능: 확인이 끝났는지 화면에서 알 수 있고 다시 열어도 결과가 남으면 좋겠다.
잘못됐을 때: 지금은 개발용 확인이라는 걸 보여주고 실패하면 다시 해볼 수 있게 하고 싶다.

정한 것
- 확인됐다는 글자만 바뀌는 게 아니라 다시 들어와도 확인 결과가 남았으면 한다. 연습용 확인이라면 실제로 본인 확인을 마쳤다고 오해하지 않게 표시하면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
