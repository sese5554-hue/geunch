# 30. 차량 세부사항 입력

대상: 차량 세부사항 입력

1) 확인하거나 적을 내용
차 설명과 옵션, 인수할 장소를 적을 수 있으면 좋겠다.

2) 처리할 일
주소와 지도 위치를 골라 저장하고 다시 확인하고 싶다.

3) 멈추고 알려야 할 부분
주소가 빠지거나 위치를 못 정했을 때는 어디를 채울지 알려주면 된다.

4) 관리할 때 지킬 기준
설명과 옵션뿐 아니라 차를 받을 주소와 지도 위치도 함께 남았으면 한다. 주소만 골랐는데 지도 위치가 없으면 무엇을 더 해야 하는지 알려주면 된다.
