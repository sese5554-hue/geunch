# 30. 차량 세부사항 입력

화면: 차량 세부사항 입력
보여줄 내용: 차 설명과 옵션, 인수할 장소를 적을 수 있으면 좋겠다.
주요 기능: 주소와 지도 위치를 골라 저장하고 다시 확인하고 싶다.
잘못됐을 때: 주소가 빠지거나 위치를 못 정했을 때는 어디를 채울지 알려주면 된다.

정한 것
- 설명과 옵션뿐 아니라 차를 받을 주소와 지도 위치도 함께 남았으면 한다. 주소만 골랐는데 지도 위치가 없으면 무엇을 더 해야 하는지 알려주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
