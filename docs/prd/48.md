# 48. 보험 선택

화면: 보험 선택
보여줄 내용: 보험별 가격이랑 설명을 비교해서 보고 싶다.
주요 기능: 하나를 고르면 선택 표시가 되고 예약 금액에도 반영되면 된다.
잘못됐을 때: 지금 제공되는 개발용 보험 예시라는 건 알 수 있으면 좋겠다.

정한 것
- 보험별 설명과 하루 가격을 비교해서 하나를 고르고 싶다. 선택한 보험이 마지막 예약 금액에도 똑같이 반영돼야 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
