# 48. 보험 선택

보험 선택

어디에서 쓰는 화면인지
보험별 가격이랑 설명을 비교해서 보고 싶다.

이 화면에서 할 일
하나를 고르면 선택 표시가 되고 예약 금액에도 반영되면 된다.

결과가 안 나올 때
지금 제공되는 개발용 보험 예시라는 건 알 수 있으면 좋겠다.

화면을 쓰는 기준
보험별 설명과 하루 가격을 비교해서 하나를 고르고 싶다. 선택한 보험이 마지막 예약 금액에도 똑같이 반영돼야 한다.
