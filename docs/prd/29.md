# 29. 차량 종류와 사양 입력

화면: 차량 종류와 사양 입력
보여줄 내용: 차 크기, 연료, 좌석 같은 정보를 고를 수 있으면 된다.
주요 기능: 기존에 넣은 값이 다시 나오고 바꾸면 저장됐으면 좋겠다.
잘못됐을 때: 좌석 수 같은 값이 이상하면 저장 전에 알려주면 좋겠다.

정한 것
- 연료와 좌석 수는 내가 고른 값으로 저장돼야 한다. 좌석이 0개처럼 말이 안 되는 값이면 저장하지 말고 다시 확인하게 해주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
