# 00. 약관 및 권한 동의

화면: 약관 및 권한 동의
보여줄 내용: 동의할 항목이랑 꼭 선택해야 하는 항목을 구분해서 보여주면 좋겠다.
주요 기능: 전체 동의를 누르면 같이 선택되고, 하나를 풀면 전체 동의도 풀리게 하고 싶다.
잘못됐을 때: 필수 항목을 안 골랐으면 어떤 걸 더 골라야 하는지 알려주면 된다.

정한 것
- 전체 동의에서 하나를 풀면 전체 동의 표시도 풀렸으면 한다. 선택 항목은 체크하지 않아도 되고, 필수 항목을 빠뜨리면 무엇이 빠졌는지 알려주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
