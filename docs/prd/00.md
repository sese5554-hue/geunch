# 00. 약관 및 권한 동의

화면: 약관 및 권한 동의

필요한 내용
동의할 항목이랑 꼭 선택해야 하는 항목을 구분해서 보여주면 좋겠다.

버튼을 누르면
전체 동의를 누르면 같이 선택되고, 하나를 풀면 전체 동의도 풀리게 하고 싶다.

빠뜨리거나 틀렸을 때
필수 항목을 안 골랐으면 어떤 걸 더 골라야 하는지 알려주면 된다.

꼭 맞출 부분
전체 동의에서 하나를 풀면 전체 동의 표시도 풀렸으면 한다. 선택 항목은 체크하지 않아도 되고, 필수 항목을 빠뜨리면 무엇이 빠졌는지 알려주면 된다.
