# 19. 예약 채팅방

기능 이름 | 예약 채팅방
볼 내용 | 예약 상대랑 주고받은 메시지가 순서대로 보이면 좋겠다.
할 수 있는 일 | 메시지를 보내고 다시 열어도 남아 있고 새 메시지가 오면 보였으면 한다.
안내할 내용 | 전송 실패는 다시 시도할 수 있고 같은 메시지가 두 개 생기지 않으면 좋겠다.
지킬 조건 | 메시지를 다시 보내도 같은 말풍선이 두 개 생기지 않았으면 한다. 나와 그 예약의 상대방만 대화 내용을 볼 수 있어야 한다.
