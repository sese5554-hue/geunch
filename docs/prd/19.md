# 19. 예약 채팅방

화면: 예약 채팅방
보여줄 내용: 예약 상대랑 주고받은 메시지가 순서대로 보이면 좋겠다.
주요 기능: 메시지를 보내고 다시 열어도 남아 있고 새 메시지가 오면 보였으면 한다.
잘못됐을 때: 전송 실패는 다시 시도할 수 있고 같은 메시지가 두 개 생기지 않으면 좋겠다.

정한 것
- 메시지를 다시 보내도 같은 말풍선이 두 개 생기지 않았으면 한다. 나와 그 예약의 상대방만 대화 내용을 볼 수 있어야 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
