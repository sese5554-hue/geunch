# 26. 호스트 차량 목록

대상: 호스트 차량 목록

1) 확인하거나 적을 내용
내가 등록한 차만 목록에 나오면 된다.

2) 처리할 일
차가 공개 중인지 준비 중인지 구별하고 저장한 내용이 목록에도 보이면 좋겠다.

3) 멈추고 알려야 할 부분
다른 사람 차가 섞이지 않고 등록한 차가 없으면 안내가 있으면 된다.

4) 관리할 때 지킬 기준
내가 등록한 차만 나와야 한다. 등록 중인 차와 공개해서 빌려줄 수 있는 차를 구별하고, 아직 차가 없으면 등록할 수 있다는 안내가 있으면 한다.
