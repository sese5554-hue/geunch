# 26. 호스트 차량 목록

화면: 호스트 차량 목록
보여줄 내용: 내가 등록한 차만 목록에 나오면 된다.
주요 기능: 차가 공개 중인지 준비 중인지 구별하고 저장한 내용이 목록에도 보이면 좋겠다.
잘못됐을 때: 다른 사람 차가 섞이지 않고 등록한 차가 없으면 안내가 있으면 된다.

정한 것
- 내가 등록한 차만 나와야 한다. 등록 중인 차와 공개해서 빌려줄 수 있는 차를 구별하고, 아직 차가 없으면 등록할 수 있다는 안내가 있으면 한다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
