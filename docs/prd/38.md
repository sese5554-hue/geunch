# 38. 개인정보 수정

기능 이름 | 개인정보 수정
볼 내용 | 지금 저장된 내 개인정보를 보고 고칠 수 있으면 된다.
할 수 있는 일 | 바꾼 내용이 저장되고 번호를 바꿀 때는 다시 확인하고 싶다.
안내할 내용 | 잘못 적은 값이나 번호 확인이 안 끝난 경우를 알려주면 좋겠다.
지킬 조건 | 이름처럼 바로 고칠 수 있는 내용과 새 번호 확인이 필요한 휴대폰 변경을 구별했으면 한다. 번호 확인에 실패하면 예전 번호를 그대로 남겨두면 된다.
