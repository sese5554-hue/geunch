# 38. 개인정보 수정

화면: 개인정보 수정
보여줄 내용: 지금 저장된 내 개인정보를 보고 고칠 수 있으면 된다.
주요 기능: 바꾼 내용이 저장되고 번호를 바꿀 때는 다시 확인하고 싶다.
잘못됐을 때: 잘못 적은 값이나 번호 확인이 안 끝난 경우를 알려주면 좋겠다.

정한 것
- 이름처럼 바로 고칠 수 있는 내용과 새 번호 확인이 필요한 휴대폰 변경을 구별했으면 한다. 번호 확인에 실패하면 예전 번호를 그대로 남겨두면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
