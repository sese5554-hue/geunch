# 49. 차량 세부사항 저장 완료

화면: 차량 세부사항 저장 완료
보여줄 내용: 차 세부사항을 저장했다는 결과와 저장한 내용을 확인하고 싶다.
주요 기능: 실제로 저장된 걸 다시 읽어서 보여주면 좋겠다.
잘못됐을 때: 저장이 안 됐으면 완료라고 나오지 않았으면 한다.

정한 것
- 기본 정보가 저장됐다는 것과 차가 공개됐다는 것을 다르게 안내했으면 한다. 저장한 차가 맞는지 다시 보여주고 나머지 등록을 이어갈 수 있으면 한다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
