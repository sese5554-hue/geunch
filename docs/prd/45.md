# 45. 게스트 예약 목록

화면: 게스트 예약 목록
보여줄 내용: 내가 요청한 예약들을 상태랑 날짜를 보고 구별하고 싶다.
주요 기능: 예약을 다시 불러와도 최신 상태로 보이면 된다.
잘못됐을 때: 예약이 없으면 없다고 알려주고 불러오기 실패랑 구분하면 좋겠다.

정한 것
- 내 예약만 날짜와 상태로 구별해서 보고 싶다. 상대방이 승인하거나 예약이 취소되었으면 다시 들어왔을 때 현재 상태가 나와야 한다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
