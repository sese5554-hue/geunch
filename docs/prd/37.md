# 37. 게스트 마이페이지

기능 이름 | 게스트 마이페이지
볼 내용 | 내 정보와 인증 상태, 계정 관리 메뉴를 한곳에서 보고 싶다.
할 수 있는 일 | 정보를 바꾸고 돌아오면 최신 내용이 보이면 된다.
안내할 내용 | 로그인 안 한 상태와 정보를 못 읽은 상태를 구별하고 싶다.
지킬 조건 | 이름이나 정보를 바꾸고 돌아오면 최신 내용으로 보였으면 한다. 로그인하지 않은 것과 잠깐 내용을 못 불러온 것을 다르게 안내해주면 된다.
