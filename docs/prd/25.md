# 25. 호스트 홈

대상: 호스트 홈

1) 확인하거나 적을 내용
내 차와 들어온 예약, 수익을 한 화면에서 대략 보고 싶다.

2) 처리할 일
등록하거나 예약 상태가 바뀌면 이 화면 숫자도 같이 맞았으면 한다.

3) 멈추고 알려야 할 부분
처음 들어와서 아무 자료가 없어도 할 수 있는 일을 알려주면 좋겠다.

4) 관리할 때 지킬 기준
등록한 차량 수, 들어온 예약 수와 수익이 실제 내 내용과 맞았으면 한다. 등록이나 예약 처리를 하고 돌아오면 바뀐 내용이 보이면 좋겠다.
