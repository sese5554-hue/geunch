# 41. 알림 설정

화면: 알림 설정
보여줄 내용: 어떤 알림을 받을지 켜고 끌 수 있으면 좋겠다.
주요 기능: 설정한 값이 저장돼서 다시 열어도 같으면 된다.
잘못됐을 때: 저장 실패면 켜진 척하지 말고 다시 해보라고 알려주면 된다.

정한 것
- 알림을 켜거나 끈 뒤 다시 들어와도 같은 설정이어야 한다. 저장에 실패했다면 바뀐 것처럼 두지 말고 다시 해보라고 알려주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
