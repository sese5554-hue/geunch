# 27. 차량 정보 수정 및 삭제

화면: 차량 정보 수정 및 삭제
보여줄 내용: 저장된 차량 내용을 보고 수정하거나 삭제할 수 있으면 좋겠다.
주요 기능: 저장한 걸 다시 열면 바뀐 내용이 나오고 숨김과 삭제는 구분됐으면 한다.
잘못됐을 때: 예약이 있어서 못 지우거나 다른 창에서 먼저 바뀌었으면 이유를 알려주면 된다.

정한 것
- 이미 예약된 차를 지우려 하면 이유를 알려주고 막았으면 한다. 다른 창에서 먼저 수정한 내용이 있으면 덮어쓰지 말고 다시 확인하게 해주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
