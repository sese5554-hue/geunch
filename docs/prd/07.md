# 07. 면허 정보 입력

화면: 면허 정보 입력
보여줄 내용: 면허 정보를 입력하고 현재 확인 상태를 볼 수 있으면 된다.
주요 기능: 입력하고 확인한 정보가 저장돼서 나중에도 볼 수 있으면 좋겠다.
잘못됐을 때: 입력이 이상하면 다시 적으라고 하고 개발용 확인이라는 것도 알려주고 싶다.

정한 것
- 번호를 입력했다는 사실만으로 실제 면허가 확인된 것은 아니다. 저장 정보·인증 상태·개발 모드를 나눠 보여준다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 외부 서비스가 연결되지 않은 부분은 개발용이라는 것을 알린다.

## 구현 순서

1. 설계: 화면에서 쓸 정보, 요청과 실패 조건을 정한다.
2. 레이아웃: 예시 내용으로 화면을 만들고 원본 시안과 비교한다.
3. 모델: 화면 상태와 요청·응답 형식을 분리한다.
4. 로직: 조회·저장, 권한과 실패 처리를 연결한다.
5. 확인: 기능 테스트와 빌드 후 실제 변경을 커밋한다.
