# 03. 로그인

화면: 로그인

필요한 내용
아이디랑 비밀번호 입력칸이 있으면 된다.

버튼을 누르면
맞게 입력하면 로그인되고 새로고침해도 로그인한 상태면 좋겠다.

빠뜨리거나 틀렸을 때
틀리면 어디로 넘어가지 말고 다시 입력하라고 보여주면 된다.

꼭 맞출 부분
새로고침했다고 로그인이 풀리지 않았으면 한다. 로그아웃하면 내 정보가 남지 않아야 하고, 비밀번호가 틀리면 다시 적을 수 있어야 한다.
