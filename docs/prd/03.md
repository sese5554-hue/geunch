# 03. 로그인

화면: 로그인
보여줄 내용: 아이디랑 비밀번호 입력칸이 있으면 된다.
주요 기능: 맞게 입력하면 로그인되고 새로고침해도 로그인한 상태면 좋겠다.
잘못됐을 때: 틀리면 어디로 넘어가지 말고 다시 입력하라고 보여주면 된다.

정한 것
- 새로고침했다고 로그인이 풀리지 않았으면 한다. 로그아웃하면 내 정보가 남지 않아야 하고, 비밀번호가 틀리면 다시 적을 수 있어야 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
