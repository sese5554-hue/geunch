# 18. 예약 상세

예약 상세

어디에서 쓰는 화면인지
내 예약의 차, 날짜, 금액과 진행 상태를 볼 수 있으면 된다.

이 화면에서 할 일
승인된 뒤 결제하거나 가능한 상태에서 취소하고 결과가 바로 바뀌면 좋겠다.

결과가 안 나올 때
다른 사람 예약은 못 보고 지금 할 수 없는 작업은 이유를 알려주고 싶다.

화면을 쓰는 기준
내 예약만 볼 수 있어야 한다. 승인 전에는 결제되지 않고, 취소한 다음에는 취소 결과와 환불이 필요한지 알 수 있으면 한다.
