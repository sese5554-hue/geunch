# 14. 대여 일정

대여 일정

어디에서 쓰는 화면인지
언제 빌리고 언제 돌려줄지 고르는 칸이 필요하다.

이 화면에서 할 일
가능한 날짜를 확인해서 고른 일정이 예약에 쓰이면 좋겠다.

결과가 안 나올 때
지난 날짜나 끝이 더 빠른 날짜를 고르면 알려주면 된다.

화면을 쓰는 기준
고른 날짜와 시간이 예약할 때도 그대로 쓰였으면 한다. 이미 지난 시간, 반납이 시작보다 빠른 일정, 빌릴 수 없는 기간은 선택하지 못하게 알려주면 된다.
