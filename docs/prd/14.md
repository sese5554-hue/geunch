# 14. 대여 일정

화면: 대여 일정
보여줄 내용: 언제 빌리고 언제 돌려줄지 고르는 칸이 필요하다.
주요 기능: 가능한 날짜를 확인해서 고른 일정이 예약에 쓰이면 좋겠다.
잘못됐을 때: 지난 날짜나 끝이 더 빠른 날짜를 고르면 알려주면 된다.

정한 것
- 고른 날짜와 시간이 예약할 때도 그대로 쓰였으면 한다. 이미 지난 시간, 반납이 시작보다 빠른 일정, 빌릴 수 없는 기간은 선택하지 못하게 알려주면 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
