# 39. 면허 관리

화면: 면허 관리
보여줄 내용: 지금 내 면허 정보와 확인 상태를 볼 수 있으면 된다.
주요 기능: 면허가 없거나 다시 확인해야 하는 상태를 알아보고 싶다.
잘못됐을 때: 자료를 못 읽은 걸 미등록이라고 잘못 보여주지 않으면 좋겠다.

정한 것
- 면허를 아직 등록하지 않은 경우와 등록한 면허의 확인 기간이 끝난 경우를 구별했으면 한다. 불러오기 실패를 미등록으로 표시하면 안 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
