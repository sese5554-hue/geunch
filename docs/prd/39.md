# 39. 면허 관리

기능 이름 | 면허 관리
볼 내용 | 지금 내 면허 정보와 확인 상태를 볼 수 있으면 된다.
할 수 있는 일 | 면허가 없거나 다시 확인해야 하는 상태를 알아보고 싶다.
안내할 내용 | 자료를 못 읽은 걸 미등록이라고 잘못 보여주지 않으면 좋겠다.
지킬 조건 | 면허를 아직 등록하지 않은 경우와 등록한 면허의 확인 기간이 끝난 경우를 구별했으면 한다. 불러오기 실패를 미등록으로 표시하면 안 된다.
