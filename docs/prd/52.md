# 52. 문의 내역

기능 이름 | 문의 내역
볼 내용 | 내가 접수한 문의의 제목, 날짜와 상태를 보고 싶다.
할 수 있는 일 | 내 문의만 나오고 새 문의도 다시 열면 확인되면 좋겠다.
안내할 내용 | 문의가 없는 경우와 내용을 못 읽은 경우를 다르게 알려주면 된다.
지킬 조건 | 내가 보낸 문의만 제목, 날짜와 처리 상태로 보고 싶다. 문의가 없는 경우와 내용을 못 불러온 경우를 다르게 알려주면 된다.
