# 44. 채팅 목록

화면: 채팅 목록
보여줄 내용: 대화 상대와 마지막 메시지, 안 읽은 내용을 구별하고 싶다.
주요 기능: 새 메시지나 읽은 상태가 목록에도 반영되면 좋겠다.
잘못됐을 때: 대화가 없으면 없다고 보여주고 불러오기 실패와 다르게 안내하면 된다.

정한 것
- 새 메시지가 오거나 읽고 돌아오면 마지막 내용과 안 읽은 개수가 맞게 바뀌었으면 한다. 내 대화만 보여야 하고 아무 대화가 없는 경우도 안내해주면 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
