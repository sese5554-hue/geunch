# 13. 차량 세부 정보

화면: 차량 세부 정보
보여줄 내용: 차 좌석 수, 연료, 옵션 같은 세부 정보를 모아서 보고 싶다.
주요 기능: 선택한 차의 정보가 맞게 나오고 읽기 편하면 된다.
잘못됐을 때: 비어 있는 정보는 없는 내용까지 있는 것처럼 보여주지 않았으면 좋겠다.

정한 것
- 좌석 수나 연료처럼 차마다 다른 내용이 그 차에 맞게 나와야 한다. 등록하지 않은 정보는 아직 정보가 없다고 보여주면 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
