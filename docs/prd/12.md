# 12. 차량 상세

차량 상세

어디에서 쓰는 화면인지
선택한 차 사진, 가격, 후기랑 간단한 설명을 보고 싶다.

이 화면에서 할 일
어느 차를 보고 있는지 주소에도 남아서 다시 열어도 같은 차가 나오면 좋겠다.

결과가 안 나올 때
없어진 차거나 사진이 없어도 알아볼 수 있게 보여주면 된다.

화면을 쓰는 기준
차 상세 주소를 복사해서 새로 열어도 같은 차가 나왔으면 한다. 더 이상 볼 수 없는 차라면 이유를 안내하고 없는 정보를 만들어 보여주지 않았으면 한다.
