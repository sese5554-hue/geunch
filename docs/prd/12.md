# 12. 차량 상세

화면: 차량 상세
보여줄 내용: 선택한 차 사진, 가격, 후기랑 간단한 설명을 보고 싶다.
주요 기능: 어느 차를 보고 있는지 주소에도 남아서 다시 열어도 같은 차가 나오면 좋겠다.
잘못됐을 때: 없어진 차거나 사진이 없어도 알아볼 수 있게 보여주면 된다.

정한 것
- 차 상세 주소를 복사해서 새로 열어도 같은 차가 나왔으면 한다. 더 이상 볼 수 없는 차라면 이유를 안내하고 없는 정보를 만들어 보여주지 않았으면 한다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
