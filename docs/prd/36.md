# 36. 호스트 수익 대시보드

화면: 호스트 수익 대시보드
보여줄 내용: 내 수익이 얼마인지랑 어떤 기준으로 더한 건지 보고 싶다.
주요 기능: 예약 금액 전체와 실제 호스트 몫이 구별됐으면 좋겠다.
잘못됐을 때: 아직 수익이 없으면 0으로 보여주고 불러오기 실패는 따로 알려주면 된다.

정한 것
- 앞으로 받을 것으로 예상하는 돈과 정산이 끝난 돈을 구별했으면 한다. 차량 이용료에서 내야 할 수수료를 뺀 금액이 내 수익으로 보이면 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
