# 04. 회원가입

화면: 회원가입

필요한 내용
아이디, 비밀번호, 닉네임, 휴대폰 번호를 적는 칸이 필요하다.

버튼을 누르면
아이디가 겹치는지 확인하고 휴대폰 확인과 약관 동의를 마치면 가입되게 하고 싶다.

빠뜨리거나 틀렸을 때
빼먹거나 잘못 적은 건 입력칸 근처에서 알려주면 좋겠다.

꼭 맞출 부분
아이디 중복 확인 뒤 내용을 바꾸면 다시 확인했으면 한다. 가입할 때도 중복 여부를 다시 봐주고, 비밀번호는 다른 사람이 그대로 볼 수 없게 보관했으면 한다.
