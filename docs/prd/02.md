# 02. 이용 유형 선택

화면: 이용 유형 선택
보여줄 내용: 차를 빌릴 건지 내 차를 빌려줄 건지 두 가지를 고를 수 있으면 된다.
주요 기능: 선택한 쪽이 눈에 띄고, 선택한 내용이 저장되면 좋겠다.
잘못됐을 때: 아무것도 안 골랐으면 먼저 하나 고르라고 알려주고 싶다.

정한 것
- 한 계정으로 차를 빌리기도 하고 빌려주기도 할 수 있으면 한다. 이번에 어떤 쪽으로 이용할지 고른 내용이 다시 들어와도 맞게 나왔으면 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
