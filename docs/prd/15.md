# 15. 예약 확인

예약 확인

어디에서 쓰는 화면인지
고른 차와 일정, 보험, 최종 예상 금액을 한 번에 보고 싶다.

이 화면에서 할 일
조건을 바꾸면 금액도 다시 맞춰서 보여주면 된다.

결과가 안 나올 때
불러오는 중이거나 금액을 확인하지 못했으면 예약된 것처럼 보이지 않으면 좋겠다.

화면을 쓰는 기준
24시간을 조금 넘기면 이틀 요금으로 계산하는 기준을 안내했으면 한다. 차량 요금, 보험료, 이용 수수료를 나눠 보여주고 마지막 금액이 서로 맞아야 한다.
