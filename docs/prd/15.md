# 15. 예약 확인

화면: 예약 확인
보여줄 내용: 고른 차와 일정, 보험, 최종 예상 금액을 한 번에 보고 싶다.
주요 기능: 조건을 바꾸면 금액도 다시 맞춰서 보여주면 된다.
잘못됐을 때: 불러오는 중이거나 금액을 확인하지 못했으면 예약된 것처럼 보이지 않으면 좋겠다.

정한 것
- 24시간을 조금 넘기면 이틀 요금으로 계산하는 기준을 안내했으면 한다. 차량 요금, 보험료, 이용 수수료를 나눠 보여주고 마지막 금액이 서로 맞아야 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
