# 31. 차량 외관 사진 등록

대상: 차량 외관 사진 등록

1) 확인하거나 적을 내용
사진 방향마다 어떤 사진을 올렸는지 보이면 좋겠다.

2) 처리할 일
사진을 올리거나 교체한 내용이 저장돼서 다시 열어도 보여야 한다.

3) 멈추고 알려야 할 부분
올리는 중이거나 실패한 걸 저장된 사진처럼 보이지 않게 하고 싶다.

4) 관리할 때 지킬 기준
어느 방향 사진을 올렸는지 알 수 있어야 한다. 사진을 바꾸면 다음에 열어도 새 사진이 나오고, 올리다 실패한 사진은 완료됐다고 나오면 안 된다.
