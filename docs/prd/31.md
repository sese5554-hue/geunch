# 31. 차량 외관 사진 등록

화면: 차량 외관 사진 등록
보여줄 내용: 사진 방향마다 어떤 사진을 올렸는지 보이면 좋겠다.
주요 기능: 사진을 올리거나 교체한 내용이 저장돼서 다시 열어도 보여야 한다.
잘못됐을 때: 올리는 중이거나 실패한 걸 저장된 사진처럼 보이지 않게 하고 싶다.

정한 것
- 어느 방향 사진을 올렸는지 알 수 있어야 한다. 사진을 바꾸면 다음에 열어도 새 사진이 나오고, 올리다 실패한 사진은 완료됐다고 나오면 안 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
