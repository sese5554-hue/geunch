# 06. 동네 인증

화면: 동네 인증
보여줄 내용: 검색한 주소랑 지금 위치를 확인할 수 있으면 좋겠다.
주요 기능: 주소를 골라 동네를 확인하고 내 동네로 저장하고 싶다.
잘못됐을 때: 위치를 못 가져오면 멈추지 말고 권한을 확인하거나 다시 해보라고 알려주면 된다.

정한 것
- 내가 고른 주소와 지금 있는 곳은 다를 수 있다. 위치를 못 가져왔으면 이유를 알려주고, 확인되지 않았는데 동네 확인이 끝났다고 나오면 안 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
