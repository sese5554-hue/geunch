# 06. 동네 인증

화면: 동네 인증

필요한 내용
검색한 주소랑 지금 위치를 확인할 수 있으면 좋겠다.

버튼을 누르면
주소를 골라 동네를 확인하고 내 동네로 저장하고 싶다.

빠뜨리거나 틀렸을 때
위치를 못 가져오면 멈추지 말고 권한을 확인하거나 다시 해보라고 알려주면 된다.

꼭 맞출 부분
내가 고른 주소와 지금 있는 곳은 다를 수 있다. 위치를 못 가져왔으면 이유를 알려주고, 확인되지 않았는데 동네 확인이 끝났다고 나오면 안 된다.
