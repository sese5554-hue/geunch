# 33. 대여 가능 일정과 요금

화면: 대여 가능 일정과 요금
보여줄 내용: 빌려줄 수 있는 기간이랑 하루 가격을 정하고 싶다.
주요 기능: 입력한 일정과 요금을 저장하고 준비가 다 된 차만 공개하고 싶다.
잘못됐을 때: 기간이 겹치거나 이미 있는 예약을 못 받게 되는 수정은 막아줬으면 한다.

정한 것
- 빌려줄 기간과 하루 요금을 저장하고 싶다. 기간이 겹치거나 이미 받은 예약에 문제가 생기는 수정은 막고, 필요한 등록을 마친 차만 공개했으면 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
