# 20. 인수 전 차량 상태

화면: 인수 전 차량 상태
보여줄 내용: 차 받기 전 사진과 주행거리를 넣을 수 있으면 된다.
주요 기능: 잠깐 저장하는 것과 최종 제출을 나눠서 처리하고 싶다.
잘못됐을 때: 사진이 부족하거나 너무 이른 시간이면 무엇 때문에 안 되는지 알려주면 좋겠다.

정한 것
- 사진을 잠깐 저장하는 것과 인수를 마치는 것을 구별했으면 한다. 인수 완료는 예약 시작 30분 전부터 할 수 있고 필요한 사진과 주행거리를 확인해야 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
