# 21. 반납 후 차량 상태

기능 이름 | 반납 후 차량 상태
볼 내용 | 차 돌려준 뒤 사진과 주행거리를 입력하고 싶다.
할 수 있는 일 | 제출한 내용이 남고 인수할 때 기록과 비교할 수 있으면 된다.
안내할 내용 | 반납 거리가 인수 때보다 적거나 사진이 빠지면 알려주면 좋겠다.
지킬 조건 | 반납할 때 적은 주행거리가 인수할 때보다 작으면 다시 확인하게 했으면 한다. 반납 자료와 뒤에서 보여주는 추가 요금의 기준이 같아야 한다.
