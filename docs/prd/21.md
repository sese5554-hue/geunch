# 21. 반납 후 차량 상태

화면: 반납 후 차량 상태
보여줄 내용: 차 돌려준 뒤 사진과 주행거리를 입력하고 싶다.
주요 기능: 제출한 내용이 남고 인수할 때 기록과 비교할 수 있으면 된다.
잘못됐을 때: 반납 거리가 인수 때보다 적거나 사진이 빠지면 알려주면 좋겠다.

정한 것
- 반납할 때 적은 주행거리가 인수할 때보다 작으면 다시 확인하게 했으면 한다. 반납 자료와 뒤에서 보여주는 추가 요금의 기준이 같아야 한다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
