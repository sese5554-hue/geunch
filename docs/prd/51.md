# 51. 게스트 매너 및 이전 평가

화면: 게스트 매너 및 이전 평가
보여줄 내용: 예약한 사람의 매너 점수랑 이전 평가를 보고 싶다.
주요 기능: 내 차 예약에 관련된 사람의 정보만 확인할 수 있으면 된다.
잘못됐을 때: 평가가 없을 때는 없다고 보여주고 아무 사람 정보나 열리면 안 된다.

정한 것
- 내 차를 예약한 게스트의 공개된 후기와 평가만 보고 싶다. 아무나 다른 사람 번호를 넣어서 개인정보를 볼 수 있으면 안 된다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
