# 23. 최종 정산 및 추가 결제

화면: 최종 정산 및 추가 결제
보여줄 내용: 이용금액과 추가 거리 요금, 지금 더 내야 하는 금액을 보고 싶다.
주요 기능: 추가로 낼 게 없으면 완료하고 있으면 개발용 결제 결과를 확인하고 싶다.
잘못됐을 때: 같은 걸 다시 눌러도 두 번 처리되지 않고 지금은 실제 결제가 아니라는 걸 알려주면 된다.

정한 것
- 인수와 반납에 적힌 거리로 추가 요금을 계산했으면 한다. 이미 낸 돈과 더 내야 할 돈을 구별하고, 실제로 받거나 돌려주지 못한 돈을 처리 완료로 표시하면 안 된다.
- 처리한 뒤 다시 불러와도 결과가 맞아야 한다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
