# 10. 차량 검색 결과

화면: 차량 검색 결과
보여줄 내용: 검색한 조건이랑 나온 차 목록, 가격을 보여주면 된다.
주요 기능: 정렬이나 페이지를 바꿔도 검색 조건은 유지됐으면 좋겠다.
잘못됐을 때: 결과가 없는 건 오류랑 다르게 알려주면 좋겠다.

정한 것
- 조건을 바꾸거나 목록의 다음 쪽으로 넘어가도 내가 고른 조건이 남았으면 한다. 새로고침해도 같은 조건으로 찾을 수 있으면 좋겠다.
- 현재 자료를 읽어 보여주는 화면으로 만든다.
- 기다리는 중, 내용이 없는 경우, 불러오기 실패를 구별한다.
- 다른 담당 화면으로 이동하는 연결은 이번 범위에서 뺀다.
- 실제 서비스와 연결되지 않은 건 연습용이라는 표시를 한다.
