# 10. 차량 검색 결과

차량 검색 결과

어디에서 쓰는 화면인지
검색한 조건이랑 나온 차 목록, 가격을 보여주면 된다.

이 화면에서 할 일
정렬이나 페이지를 바꿔도 검색 조건은 유지됐으면 좋겠다.

결과가 안 나올 때
결과가 없는 건 오류랑 다르게 알려주면 좋겠다.

화면을 쓰는 기준
조건을 바꾸거나 목록의 다음 쪽으로 넘어가도 내가 고른 조건이 남았으면 한다. 새로고침해도 같은 조건으로 찾을 수 있으면 좋겠다.
