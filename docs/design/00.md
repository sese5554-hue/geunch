# 약관 동의

먼저 전체 동의와 개별 체크가 같이 바뀌는 화면을 만든다.

## 화면

개인정보 수집·이용, 제3자 제공, 위치정보 이용약관, 위치정보 수집·이용은 필수다. 앱·문자·이메일 혜택 알림은 선택이다. 필수 항목만 골라도 계속할 수 있다. 전체 동의 표시는 일곱 항목을 모두 골랐을 때만 켠다.

저장 중에는 다시 누를 수 없게 한다. 실패하면 선택한 내용은 남기고 이유를 보여준다. 저장되면 완료 안내를 띄우되 다른 담당 화면으로 이동하지 않는다.

## 요청

- GET /api/terms: 현재 약관 버전과 필수·선택 항목.
- GET /api/consents/current: 브라우저 쿠키로 마지막 저장 내용을 확인. 아직 저장한 내용이 없으면 null.
- POST /api/consents: 현재 버전과 일곱 항목의 동의 여부를 저장하고, HttpOnly 쿠키로 기록 번호를 보관.

필수 누락·알 수 없는 항목·잘못된 자료형은 서버에서도 거절한다. 이전 버전 약관은 새 약관을 다시 확인하도록 안내한다. 다른 브라우저의 동의 번호는 URL이나 요청 본문으로 조회하지 않는다.

## 저장

실행할 때 MariaDB 연결값을 사용한다. 테스트에서는 저장소를 주입해 화면/API 규칙을 따로 확인한다. 동의 항목과 약관 버전을 함께 저장한다.

## 만들 파일

- src/features/terms/TermsPage.tsx: 체크박스와 안내.
- shared/terms.ts: 항목, 요청 규칙, 전체 동의 계산.
- server/consents.ts: 동의 저장소와 API.
- server/database.ts: MariaDB 연결.
- tests/terms.test.ts: 선택 규칙과 필수 항목 검사.
- tests/consents.test.ts: 조회·저장·잘못된 요청·재조회.
