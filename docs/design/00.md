# 약관 동의

가입하기 전에 어떤 약관에 동의해야 하는지 보고 싶어.
개인정보 수집·이용, 다른 곳에 개인정보를 제공하는 것, 위치정보 이용약관, 위치정보를 모아서 사용하는 것은 꼭 확인하게 해줘.
앱·문자·이메일로 혜택을 받는 건 안 골라도 이용할 수 있어야 해.

- 전체 동의를 누르면 전부 체크되고, 하나만 풀어도 전체 동의 표시는 풀리게 해줘.
- 필수 항목을 빼먹으면 어떤 걸 더 골라야 하는지 알려줘.
- 저장하는 동안은 버튼을 다시 누르지 못하게 해줘.
- 저장에 실패하면 체크한 건 남겨두고 다시 해볼 수 있게 해줘.
- 저장하고 다시 들어오면 전에 고른 내용이 그대로 나왔으면 해.
- 약관이 바뀌면 예전 선택만 보고 넘어가지 말고 다시 확인하게 해줘.
- 다른 사람이 저장한 동의 내용은 볼 수 없게 해줘.
- 다른 담당 화면으로 넘어가는 건 나중에 같이 맞출게.
