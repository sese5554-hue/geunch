# 내 정보

내 이름, 가린 전화번호, 현재 이용 유형과 인증 상태를 한곳에서 확인한다.

- GET /api/me로 세션에 해당하는 사용자 정보만 불러온다.
- 로그인하지 않은 상태는 로그인 안내, 연결 실패는 재시도 안내로 구별한다.
- 이름과 전화번호는 현재 DB 값을 사용한다. 비밀번호와 세션 비밀값은 응답에 넣지 않는다.
- 인증 종류별로 완료·확인 전·만료를 구별한다. 개발 인증이면 개발용 표시를 한다.
- 창으로 돌아오거나 다시 불러오기를 누르면 최신 정보로 갱신한다.
- 로그아웃하면 서버 세션도 지우고 화면에 이름이나 전화번호가 남지 않게 한다.
- 프로필 수정·면허·결제수단 화면으로 가는 메뉴는 해당 기능을 구현하면서 연결한다.
- 개발 계정 접속은 DEV_LOGIN을 켠 로컬 개발에서만 제공한다.

화면: src/Profile.tsx / 사용자 형식: shared/profile.ts / 조회·로그아웃: server/profile.ts / DB: users, sessions, verifications.
