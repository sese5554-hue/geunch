# 내 정보

프롬프트:
나는 내 정보 화면을 만들려고 해. 이름, 전화번호, 차를 빌리는 쪽인지 빌려주는 쪽인지, 인증은 끝났는지 한곳에 보였으면 해.

- 로그인 안 했으면 로그인해야 한다고 알려줘.
- 잠깐 내용을 못 불러온 거면 로그인이 안 된 것처럼 보이지 말고 다시 불러올 수 있게 해줘.
- 전화번호는 가운데를 가려서 보여줘.
- 내 계정 내용만 나오고 비밀번호는 보여주지 말아줘.
- 본인 확인, 동네 확인, 운전면허를 나눠서 끝났는지, 아직 안 했는지, 기간이 지났는지 알려줘.
- 연습용 확인이라면 그 표시도 넣어줘.
- 이름을 바꾸고 돌아오거나 다시 불러오기를 누르면 최신 내용이 보였으면 해.
- 로그아웃하면 내 이름과 전화번호가 남지 않고, 예전에 로그인한 내용으로 다시 내 정보를 볼 수도 없게 해줘.
- 이름 수정, 면허 변경, 결제수단은 각각 만들면서 연결할게.
- 연습용 계정은 개발할 때만 쓸 수 있게 해줘.
