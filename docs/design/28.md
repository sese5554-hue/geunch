# 차량 기본 정보

차 이름, 연식, 차량번호, 동네를 입력해서 우선 초안으로 저장한다. 공개와 대여 일정은 다음 화면에서 다룬다.

- 로그인한 호스트만 등록하고 자기 초안만 다시 볼 수 있다.
- 서버가 로그인 세션에서 소유자를 정한다. 요청 본문의 사용자 번호를 믿지 않는다.
- 필수 항목, 연식 범위, 차량번호 형식을 화면과 서버에서 확인한다.
- 차량번호의 띄어쓰기는 없애고 같은 번호의 중복 등록은 DB에서도 막는다.
- 저장 중 중복 클릭을 막는다. 실패하면 입력값을 유지한다.
- 저장 후 초안 번호를 주소에 남겨 새로고침해도 저장 내용을 확인한다.
- POST /api/vehicles로 초안 생성, GET /api/vehicles/:id로 자기 초안 조회.
- 개발 계정 접속은 DEV_LOGIN을 켠 로컬 개발에서만 제공한다. 운영 로그인 대신 쓰지 않는다.

화면: src/VehicleDraft.tsx / 입력 형식: shared/vehicles.ts / 저장: server/vehicles.ts / DB: vehicles, users, sessions.
