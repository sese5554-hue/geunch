# 차량 기본 정보 등록

내 쪽은 차를 등록하는 화면이야. 차 이름, 연식, 차량번호, 동네를 적어서 먼저 저장하고 싶어.

- 차를 빌려주는 계정으로 로그인한 사람만 등록할 수 있게 해줘.
- 내가 등록한 차는 내가 다시 볼 수 있고 다른 사람은 못 보게 해줘.
- 이름이나 동네를 빼먹었거나 연식이 말이 안 되면 알려줘.
- 차량번호에 띄어쓰기가 있어도 같은 차면 같은 번호로 봐줘.
- 이미 등록된 번호면 왜 저장이 안 되는지 알려줘.
- 저장 버튼을 연달아 눌러도 같은 차가 두 번 등록되지 않았으면 해.
- 실패해도 적은 내용은 남겨줘. 성공하면 다시 열어도 저장한 내용이 나와야 해.
- 기본 정보만 넣은 차는 아직 검색에 공개하지 말아줘.
- 사진, 빌려줄 날짜랑 공개는 다음 화면에서 만들게.
- 연습용 계정은 개발할 때만 쓰고 실제 회원 로그인이라고 표시하지 말아줘.
