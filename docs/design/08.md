# 동네 차량 목록

먼저 동네와 차량 이름, 하루 예산으로 차를 찾는 화면을 만든다. 지도와 날짜 예약은 다음 기능에서 구현한다.

- 동네를 입력하지 않으면 동네를 정해 달라고 안내한다.
- 검색을 누르면 선택한 조건으로 GET /api/vehicles를 호출한다.
- 검색 조건은 주소에 남겨 새로고침해도 유지한다.
- 새 검색 중 이전 요청은 취소해 예전 결과가 새 목록을 덮지 않게 한다.
- 로딩, 차량 없음, 서버 실패를 구별하고 실패 시 재시도할 수 있게 한다.
- 차량명·연식·연료·좌석·하루 요금을 표시한다. 숨겨진 차와 등록 중인 초안은 검색에 나오면 안 된다.
- MariaDB의 공개 차량만 검색하고 인수 상세주소나 차량번호는 공개하지 않는다.
