# 23. 최종 정산 및 추가 결제

## 기능 정리

프롬프트:
차량 이용을 마친 뒤 추가 금액을 정산하는 화면을 만들어. 어떤 돈을 더 내거나 돌려받는지 PRD에 적어.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

기능별 화면 틀 만들기
프롬프트:
주행거리로 생긴 추가 요금과 이미 낸 돈, 남은 금액을 나눠서 표시해. 금액이 왜 나왔는지도 알 수 있게 해.

결과:
서로 관련 있는 내용과 버튼을 모았다.
사용한 파일: apps/web/src/pages/Shared.tsx:393 (Settlement)

조회와 버튼 연결
프롬프트:
인수와 반납에 저장한 거리로 추가 요금을 계산해. 예약할 때 정한 요금 기준을 쓰고, 실제 처리가 끝나야 정산 완료로 표시해.

결과:
인수·반납 거리와 예약 당시 요금 기준으로 추가 요금을 계산하도록 만들었다. 낸 금액·남은 금액과 정산 처리 상태를 나눠 표시하도록 만들었다.
포함거리보다 적게 탔다고 초과 요금이 음수가 되지 않도록 0과 비교하도록 만들었다. 거리가 잘못 감소한 경우는 그 전에 거절하도록 만들었다.
사용한 파일: apps/web/src/pages/Shared.tsx:393 (Settlement)

계정과 결과 확인
프롬프트:
화면에 나온 합계가 정산에 쓰인 금액과 같은지 확인해. 받거나 돌려주지 못한 돈이 완료로 표시되면 고쳐.

결과:
관련 화면과 처리 코드를 확인하고 기존 검사 기록을 함께 정리했다.
