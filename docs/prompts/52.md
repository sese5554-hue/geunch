# 52. 문의 내역

## 기능 정리

프롬프트:
근차에서 '문의 내역' 부분을 만들어.
내가 넣은 문의 내역만 표시해 제목 날짜랑 처리 상태도 같이 표시해.
이 내용으로 PRD 작성해. 화면에 나올 내용이랑 눌렀을 때 할 일을 정리해. 다른 담당 화면으로 넘어가는 건 나중에 연결해.
