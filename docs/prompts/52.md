# 52. 문의 내역

## 기능 정리

프롬프트:
내가 접수한 문의를 모아서 보는 화면을 만들어. 제목과 날짜, 처리 상태가 보이게 PRD 써.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

조회와 버튼 연결
프롬프트:
내 문의만 불러오고 새로 접수한 것도 다시 들어오면 표시해. 문의가 없는 것과 내용을 못 불러온 것은 다르게 안내해.

결과:
현재 사용자가 접수한 문의만 조회하도록 연결했다. 문의가 없을 때와 조회에 실패했을 때를 구별하도록 만들었다.
서버가 세션에서 현재 사용자를 확인해 WHERE user_id 조건을 만든다. 화면에서 임의로 보낸 사용자 ID로 내역을 고르지 않는다.
