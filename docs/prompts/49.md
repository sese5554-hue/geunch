# 49. 차량 세부사항 저장 완료

## 기능 정리

차 세부사항을 저장했다는 결과와 저장한 내용을 확인하고 싶다.
실제로 저장된 걸 다시 읽어서 보여주면 좋겠다.
저장이 안 됐으면 완료라고 나오지 않았으면 한다.

## 단계별 프롬프트

처리 결과 남기기
프롬프트:
방금 저장한 차량을 다시 보여주고 어떤 차가 저장됐는지 표시해. 저장된 것과 공개된 것은 구별하고, 나머지 등록을 이어갈 수 있게 해.

결과:
차량 관리에 필요한 내용과 처리할 일, 막아야 할 변경을 PRD로 정리했다.
저장한 차량을 다시 조회해 어떤 차가 저장됐는지 보여주도록 만들었다. 저장된 초안과 공개된 차량 상태를 구별하도록 만들었다.
서버 저장이 실패했거나 일부 값이 달라졌을 수 있다. 완료 화면에서는 실제 저장 결과를 조회해 확인하도록 만들었다.
