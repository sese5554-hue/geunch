프롬프트:
선택한 차의 사진, 가격, 후기와 설명을 보여주는 상세 화면을 만들어. 어떤 내용을 보여줄지 PRD로 정리해.

결과:

## 단계별 프롬프트

실제 내용으로 바꾸기
프롬프트:
차 상세 주소를 복사해서 바로 열어도 같은 차가 나오게 해. 사진이 없으면 빈 자리 안내를 넣고, 볼 수 없는 차면 찾을 수 없다고 알려.

결과:
주소에 들어 있는 차량 번호로 상세 정보를 다시 읽도록 연결했다. 이전 목록 화면을 거치지 않고 주소를 바로 열어도 조회할 수 있게 만들었다.
직접 주소로 들어오면 이전 목록 상태가 없다. 차량 ID로 다시 조회해야 새로고침과 직접 접근을 처리할 수 있다.
