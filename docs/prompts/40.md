# 40. 결제수단 관리

## 기능 정리

프롬프트:
내 결제수단 목록을 만들어. 기본으로 쓸 것을 고르고 필요 없는 것을 지우는 기능으로 PRD 정리해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

조회와 버튼 연결
프롬프트:
기본 결제수단은 하나만 고르게 해. 삭제하면 목록을 갱신하고, 삭제에 실패했으면 없어진 것처럼 표시하지 마. 등록한 게 없으면 안내를 넣어.

결과:
내 결제수단만 조회·변경하도록 만들었다. 기본 결제수단을 바꿀 때 다른 항목의 기본 지정도 함께 정리하도록 만들었다.
여러 카드의 기본 상태가 함께 바뀌어야 하도록 만들었다. 중간 상태만 저장되거나 동시 변경이 엇갈리지 않게 서버에서 묶어 처리하도록 만들었다.
