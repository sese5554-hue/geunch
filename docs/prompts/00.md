# 00. 약관 및 권한 동의

## 기능 정리

프롬프트:
가입 전에 약관에 동의하는 화면을 만들어. 꼭 동의해야 하는 것과 선택해도 되는 것을 나누고, 전체 동의도 넣어. 이 내용으로 PRD 정리해.

결과:
입력할 내용, 버튼을 누른 뒤 바뀔 내용, 안내 문구를 PRD에 나눠 적었다.

## 단계별 프롬프트

동의와 입력 내용 처리
프롬프트:
전체 동의를 누르면 전부 체크하고, 하나를 풀면 전체 동의도 풀리게 해. 필수 항목만 골라도 넘어갈 수 있게 하고 체크한 내용은 저장해.

결과:
전체 동의와 일곱 개별 항목이 연결되도록 만들었다. 필수 네 항목을 확인하고 선택 항목은 거절한 상태로도 동의 내용을 저장하도록 연결했다.
choices에 있는 선택값을 배열로 꺼낸 뒤 전부 선택됐는지 확인하도록 만들었다. 필수 동의 확인은 서버의 동의 규칙에서도 처리하도록 만들었다.
