# 45. 게스트 예약 목록

## 기능 정리

프롬프트:
근차에서 '게스트 예약 목록' 부분을 만들어.
내 예약 목록에 날짜랑 상태 표시해 예약 없는 경우도 안내해.
이 내용으로 PRD 작성해. 화면에 나올 내용이랑 눌렀을 때 할 일을 정리해. 다른 담당 화면으로 넘어가는 건 나중에 연결해.

## 단계별 프롬프트

어떤 순서로 만들지 정하기
프롬프트:
내 예약 목록에 날짜랑 상태 표시해 예약 없는 경우도 안내해.
아직 코드는 만들지 마. 먼저 어떤 순서로 만들지 정리하고 필요한 파일을 알려.

화면 먼저 만들기
프롬프트:
'게스트 예약 목록' 화면부터 만들어.
내 예약 목록에 날짜랑 상태 표시해 예약 없는 경우도 안내해.
지금은 예시 내용으로 화면만 만들어. 입력칸이랑 버튼을 알아보기 쉽게 배치해.

화면에 들어갈 내용 정리하기
프롬프트:
'게스트 예약 목록'에 보이는 내용을 실제로 불러올 수 있게 정리해. 예시로 넣은 값은 실제 내용이랑 구분해. 내용이 바뀌면 다시 불러와서 표시해.

눌렀을 때 동작하게 하기
프롬프트:
내 예약 목록에 날짜랑 상태 표시해 예약 없는 경우도 안내해.
이제 예시 대신 실제로 불러온 내용을 표시해. 기다리는 동안 표시를 넣고 실패하면 이유를 알려.

직접 확인하고 마무리하기
프롬프트:
'게스트 예약 목록' 내용을 PRD랑 비교해서 빠진 기능을 고쳐. 새로고침한 뒤에도 맞게 나오는지 확인해. 문제가 있으면 고치고 바꾼 파일을 알려.

## 추가 확인

추가로 물어볼 말
프롬프트:

원인을 찾아서 고쳐. 바꾼 부분이랑 이유를 설명해.

설명이 어려울 때
프롬프트:
'게스트 예약 목록'에 나오는 내용이 어디에서 오는지 설명해. 화면에 보이는 것 하나를 골라서 어떤 순서로 가져오는지 설명해.
