# 45. 게스트 예약 목록

## 기능 정리

프롬프트:
내 예약을 모아서 보는 화면을 만들어. 날짜와 현재 상태가 보이게 PRD 작성해.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

실제 내용으로 바꾸기
프롬프트:
내가 요청한 예약만 불러와서 표시해. 승인되거나 취소된 예약은 현재 상태로 보여주고, 예약이 없는 것과 목록을 못 읽은 것은 나눠서 안내해.

결과:
내 예약을 날짜와 상태로 조회하도록 연결했다. 다시 요청할 때 예약 만료 등 현재 상태를 확인해 목록을 보여주도록 만들었다.
요청 유효시간이 지나면 사용자 행동 없이도 상태가 달라질 수 있다. 조회 전 만료 조건을 확인해 최신 상태를 돌려준다.
사용한 파일: apps/web/src/pages/Guest.tsx:668 (GuestBookings)
