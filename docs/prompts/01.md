# 01. 홈 둘러보기

## 처음 부탁할 내용

프롬프트:
내 담당은 차를 찾고 빌리는 쪽이야. '홈 둘러보기'에서 사용자가 할 일을 정리해봤어.
이걸 기준으로 이 화면의 PRD를 작성해줘. 화면에 뭐가 나오는지, 뭘 누르면 어떻게 되는지 알 수 있게 써줘.

이 화면에서 필요한 건 이거야.
- 로그인 안 해도 차가 어떤 식으로 보이는지 먼저 볼 수 있으면 좋겠어.
- 차 목록을 둘러볼 수 있고 지금 보고 있는 조건을 알 수 있으면 돼.
- 보여줄 차가 없어도 빈 화면처럼 보이지 않았으면 좋겠어.

원래 있는 화면 모양이랑 공통으로 쓰는 부분은 그대로 써줘.
다른 담당 화면으로 넘어가는 연결은 나중에 같이 맞출게.

## 만들면서 부탁할 내용

어떤 순서로 만들지 정하기
프롬프트:
사용자가 이 화면에 들어와서 뭘 보고 뭘 누르는지부터 정리해줘. 아직 화면을 만들지는 말고.
로그인 안 한 사람도 차 목록은 먼저 둘러볼 수 있게 해줘.
만들 파일이랑 수정할 파일을 먼저 알려줘. 아직 코드는 만들지 말아줘.

화면 먼저 만들기
프롬프트:
먼저 예시로 화면을 만들어줘. 실제로 눌러보면서 배치가 괜찮은지 보고 싶어.
로그인 안 해도 차가 어떤 식으로 보이는지 먼저 볼 수 있으면 좋겠어.
일단 어떻게 보이는지 확인하고 다음으로 넘어가고 싶어.

화면에 들어갈 내용 정리하기
프롬프트:
예시 내용을 나중에 실제 차량이나 예약 내용으로 바꿀 수 있게 정리해줘. 어디를 바꾸면 되는지도 쉽게 알려줘.
차 목록을 둘러볼 수 있고 지금 보고 있는 조건을 알 수 있으면 돼.
화면에 적힌 글자랑 실제로 바뀌는 내용을 나눠줘. 파일을 나누면 왜 나누는지도 설명해줘.

눌렀을 때 동작하게 하기
프롬프트:
이제 예시 대신 실제로 불러온 내용을 보여줘. 다시 들어왔을 때도 현재 내용이 나오게 해줘.
로그인 안 한 사람도 차 목록은 먼저 둘러볼 수 있게 해줘.
보여줄 차가 없어도 빈 화면처럼 보이지 않았으면 좋겠어.
처리 중에는 기다리는 표시를 보여줘. 실패했는데 완료됐다고 나오면 안 돼.

직접 확인하고 마무리하기
프롬프트:
사용자처럼 처음부터 눌러볼게. 조건을 바꿨을 때랑 다시 들어왔을 때 뭘 확인해야 하는지 적어줘.
처음 적은 PRD랑 비교해서 빠진 기능이 있는지도 봐줘.
잘 되는 경우랑 안 되는 경우를 나눠서 확인하고, 다른 담당자랑 합칠 때 맞춰야 할 것도 알려줘.

## 잘 안 되거나 설명이 어려울 때

추가로 물어볼 말
프롬프트:
로그인 안 했는데 자꾸 로그인하라고 나와. 둘러보기는 볼 수 있어야 하잖아?
지금 코드에서 이 경우가 생길 수 있는지 확인해줘. 고쳐야 하면 어디를 바꾸는지랑 이유도 알려줘.

프롬프트:
차 구경만 하는데도 내가 누구인지 알아야 해? 예약할 때만 로그인하면 안 돼?
이 화면을 예로 들어서 쉬운 말로 설명해줘.
