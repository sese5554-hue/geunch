# 14. 대여 일정

## 기능 정리

프롬프트:
차를 빌릴 시간과 반납할 시간을 고르는 화면을 만들어. 빌릴 수 없는 일정은 고르지 못하게 PRD 정리해.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

화면 흐름 만들기
프롬프트:
시작 날짜와 시간, 반납 날짜와 시간을 고를 수 있게 배치해. 지금 고른 기간도 같이 표시해.

결과:
내용을 보고 누르는 순서에 맞춰 화면을 배치했다.
사용한 파일: apps/web/src/pages/Guest.tsx:394 (Reservation)

실제 내용으로 바꾸기
프롬프트:
고른 기간에 차를 빌릴 수 있는지 확인해. 지난 시간이나 반납이 더 빠른 일정은 알려주고 막아. 고른 일정은 예약할 때 그대로 써.

결과:
시작보다 종료가 늦은지 확인하고 차량을 빌릴 수 있는 기간을 조회하도록 연결했다. 잘못된 기간은 금액 계산 전에 거절하도록 만들었다.
시간대가 있는 ISO 형식으로 전달해 같은 시점을 비교하도록 만들었다. 서버는 이 값으로 기간과 차량 가용 시간을 검사하도록 만들었다.
사용한 파일: apps/web/src/pages/Guest.tsx:394 (Reservation)
