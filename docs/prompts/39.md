# 39. 면허 관리

## 기능 정리

지금 내 면허 정보와 확인 상태를 볼 수 있으면 된다.
면허가 없거나 다시 확인해야 하는 상태를 알아보고 싶다.
자료를 못 읽은 걸 미등록이라고 잘못 보여주지 않으면 좋겠다.

## 단계별 프롬프트

조회와 버튼 연결
프롬프트:
내가 등록한 면허 내용과 확인 상태를 표시해. 아직 등록하지 않은 것과 확인 기간이 끝난 것을 구별해. 내용을 못 불러온 걸 미등록으로 표시하지 마.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.
저장된 면허 내용과 인증의 현재 상태를 함께 보여주도록 만들었다. 확인 기간 만료와 미등록을 구별하도록 만들었다.
저장된 내용이 있다는 사실과 현재 유효한 확인 결과인지는 다르다. 만료된 상태로 예약 조건을 통과시키지 않도록 하도록 만들었다.
