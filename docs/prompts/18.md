# 18. 예약 상세

## 기능 정리

프롬프트:
내 예약의 차, 날짜, 금액과 진행 상태를 보는 상세 화면을 만들어. 결제와 취소가 가능한 시점도 PRD에 정리해.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

화면 흐름 만들기
프롬프트:
예약 내용을 먼저 보여주고 지금 할 수 있는 결제나 취소 버튼을 넣어. 아직 할 수 없는 작업은 이유를 표시해.

결과:
내용을 보고 누르는 순서에 맞춰 화면을 배치했다.
사용한 파일: apps/web/src/pages/BookingDetail.tsx:24 (BookingDetail)

실제 내용으로 바꾸기
프롬프트:
호스트가 승인한 예약만 결제할 수 있게 해. 취소하면 바뀐 상태를 다시 표시하고, 내 예약이 아니면 보거나 바꾸지 못하게 막아.

결과:
예약 참여자와 현재 상태를 확인하도록 만들었다. 승인 전 결제를 거절하고 결제·취소 뒤에는 바뀐 예약 결과를 다시 읽도록 연결했다.
버튼을 거치지 않고 요청할 수도 있다. 서버가 예약 참여자와 상태를 검사해야 잘못된 결제·취소를 막을 수 있다.
사용한 파일: apps/web/src/pages/BookingDetail.tsx:24 (BookingDetail)

앞뒤로 이동하며 확인
프롬프트:
결제 전후와 취소 후 상태가 맞는지 확인해. 결제나 환불에 실패했는데 완료로 나오는 부분이 있으면 고쳐.

결과:
관련 화면과 처리 코드를 확인하고 기존 검사 기록을 함께 정리했다.
