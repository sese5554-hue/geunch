# 33. 대여 가능 일정과 요금

## 처음 부탁할 내용

차를 올리고 관리하는 부분을 맡았어. 이번에 필요한 건 '대여 가능 일정과 요금'이야.
내가 적은 내용으로 PRD를 만들어줘. 저장되는 내용하고 잘못 입력했을 때 어떻게 할지가 분명했으면 해.

이 화면에서 필요한 건 이거야.
- 빌려줄 수 있는 기간이랑 하루 가격을 정하고 싶어.
- 입력한 일정과 요금을 저장하고 준비가 다 된 차만 공개하고 싶어.
- 기간이 겹치거나 이미 있는 예약을 못 받게 되는 수정은 막아줬으면 해.

원래 있는 화면 모양이랑 공통으로 쓰는 부분은 그대로 써줘.
다른 담당 화면으로 넘어가는 연결은 나중에 같이 맞출게.

## 만들면서 부탁할 내용

어떤 순서로 만들지 정하기
이 기능을 만들기 전에 내가 준비할 내용부터 정리해줘. 다른 담당자랑 맞춰야 할 것도 알려줘.
대여 가능한 기간이랑 하루 요금 저장하게 해줘 기간 겹치거나 공개 준비 안 됐으면 알려주고.
만들 파일이랑 수정할 파일을 먼저 알려줘. 아직 코드는 만들지 말아줘.

화면 먼저 만들기
일단 화면 모양부터 잡아줘. 예시를 넣어서 어디에 무엇이 나오는지 확인할 수 있게 해줘.
빌려줄 수 있는 기간이랑 하루 가격을 정하고 싶어.
일단 어떻게 보이는지 확인하고 다음으로 넘어가고 싶어.

화면에 들어갈 내용 정리하기
차마다 내용이 다를 텐데 한 차량의 내용이 다른 차량에 섞이지 않게 정리해줘. 예시로 넣은 값도 구분해줘.
입력한 일정과 요금을 저장하고 준비가 다 된 차만 공개하고 싶어.
화면에 적힌 글자랑 실제로 바뀌는 내용을 나눠줘. 파일을 나누면 왜 나누는지도 설명해줘.

눌렀을 때 동작하게 하기
이제 누르면 실제로 저장되거나 처리되게 연결해줘. 성공한 경우와 실패한 경우를 구분해서 알려줘.
대여 가능한 기간이랑 하루 요금 저장하게 해줘 기간 겹치거나 공개 준비 안 됐으면 알려주고.
기간이 겹치거나 이미 있는 예약을 못 받게 되는 수정은 막아줬으면 해.
처리 중에는 기다리는 표시를 보여줘. 실패했는데 완료됐다고 나오면 안 돼.

직접 확인하고 마무리하기
내 차량을 관리한다고 생각하고 확인해볼게. 저장한 뒤 다시 열었을 때랑 다른 차량을 골랐을 때 확인할 것도 알려줘.
처음 적은 PRD랑 비교해서 빠진 기능이 있는지도 봐줘.
잘 되는 경우랑 안 되는 경우를 나눠서 확인하고, 다른 담당자랑 합칠 때 맞춰야 할 것도 알려줘.

## 잘 안 되거나 설명이 어려울 때

추가로 물어볼 말
요금 넣었는데 REGISTRATION_INCOMPLETE라면서 공개가 안 돼.
지금 코드에서 이 경우가 생길 수 있는지 확인해줘. 고쳐야 하면 어디를 바꾸는지랑 이유도 알려줘.

빌려줄 날짜 바꾸는 건데 왜 예전 예약까지 찾아봐?
이 화면을 예로 들어서 쉬운 말로 설명해줘.
