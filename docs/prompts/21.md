# 21. 반납 후 차량 상태

## 기능 정리

프롬프트:
차를 반납할 때 사진과 주행거리를 적는 화면을 만들어. 반납 기록을 남기는 내용으로 PRD 작성해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

기능별 화면 틀 만들기
프롬프트:
반납 사진과 주행거리를 입력할 수 있게 해. 입력 중인 내용과 반납을 마친 상태를 구별해.

결과:
서로 관련 있는 내용과 버튼을 모았다.
사용한 파일: apps/web/src/pages/Shared.tsx:183 (Inspection), apps/web/src/pages/Shared.tsx:216 (InspectionForm)

조회와 버튼 연결
프롬프트:
반납 기록을 저장하고 이후 정산에서 같은 거리를 쓰게 해. 반납 주행거리가 인수 때보다 작으면 다시 확인하게 해.

결과:
반납 주행거리가 인수 때보다 작지 않은지 확인하도록 만들었다. 반납 자료와 추가 요금 계산에 쓸 기초 자료를 함께 저장하도록 연결했다.
반납 주행거리로 초과 요금이 결정된다. 제출과 정산 기초 데이터 저장을 함께 처리해 뒤의 정산 화면이 같은 값을 조회하도록 하도록 만들었다.
사용한 파일: apps/web/src/pages/Shared.tsx:183 (Inspection), apps/web/src/pages/Shared.tsx:216 (InspectionForm)
