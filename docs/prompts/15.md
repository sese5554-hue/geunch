# 15. 예약 확인

## 기능 정리

프롬프트:
예약하기 전에 차, 일정, 보험과 금액을 한 번에 확인하는 화면을 만들어. 무엇을 보여줄지 PRD로 정리해.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

화면 흐름 만들기
프롬프트:
선택한 차와 일정을 위에 표시하고, 차량 요금과 보험료, 수수료를 나눠서 표시해. 맨 아래에는 합계를 표시해.

결과:
내용을 보고 누르는 순서에 맞춰 화면을 배치했다.
사용한 파일: apps/web/src/pages/Guest.tsx:394 (Reservation), apps/web/src/pages/Guest.tsx:620 (Quote)

실제 내용으로 바꾸기
프롬프트:
일정이나 보험을 바꾸면 금액도 다시 계산해. 금액을 아직 확인하지 못했으면 예약된 것처럼 보이지 않게 해.

결과:
대여 시간을 24시간 단위로 올려 일수를 계산하도록 만들었다. 차량 요금·보험료·수수료를 합친 견적을 받아 보여주도록 만들었다.
현재 요금 정책은 남는 시간이 있으면 대여 일수를 올려 계산하도록 만들었다. 계산법을 바꾸려면 정책과 서버 계산을 함께 바꿔야 하도록 만들었다.
사용한 파일: apps/web/src/pages/Guest.tsx:394 (Reservation), apps/web/src/pages/Guest.tsx:620 (Quote)
