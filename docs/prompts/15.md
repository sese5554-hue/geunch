# 15. 예약 확인

## 기능 정리

프롬프트:
근차에서 '예약 확인' 부분을 만들어.
예약 전에 차랑 일정 보험 금액 한 번에 확인하게 해 조건 바꾸면 금액도 다시 보여주고.
이 내용으로 PRD 작성해. 화면에 나올 내용이랑 눌렀을 때 할 일을 정리해. 다른 담당 화면으로 넘어가는 건 나중에 연결해.

## 단계별 프롬프트

어떤 순서로 만들지 정하기
프롬프트:
예약 전에 차랑 일정 보험 금액 한 번에 확인하게 해 조건 바꾸면 금액도 다시 보여주고.
아직 코드는 만들지 마. 먼저 어떤 순서로 만들지 정리하고 필요한 파일을 알려.

화면 먼저 만들기
프롬프트:
'예약 확인' 화면부터 만들어.
예약 전에 차랑 일정 보험 금액 한 번에 확인하게 해 조건 바꾸면 금액도 다시 보여주고.
지금은 예시 내용으로 화면만 만들어. 입력칸이랑 버튼을 알아보기 쉽게 배치해.

화면에 들어갈 내용 정리하기
프롬프트:
'예약 확인'에서 입력하거나 고른 내용을 정리해. 화면에서 잠깐 쓰는 값과 저장할 값을 구분해. 입력한 내용이 어디에 저장되는지 설명해.

눌렀을 때 동작하게 하기
프롬프트:
예약 전에 차랑 일정 보험 금액 한 번에 확인하게 해 조건 바꾸면 금액도 다시 보여주고.
버튼을 누르면 실제로 저장되거나 처리되게 만들어. 기다리는 동안 표시를 넣고 실패하면 이유를 알려.

직접 확인하고 마무리하기
프롬프트:
'예약 확인' 내용을 PRD랑 비교해서 빠진 기능을 고쳐. 새로고침한 뒤에도 맞게 나오는지 확인해. 문제가 있으면 고치고 바꾼 파일을 알려.

## 추가 확인

추가로 물어볼 말
프롬프트:
하루 조금 넘게 골랐는데 금액이 내가 계산한 거랑 달라.
원인을 찾아서 고쳐. 바꾼 부분이랑 이유를 설명해.

설명이 어려울 때
프롬프트:
'예약 확인'에서 버튼을 누른 다음 내용이 어디로 가는지 설명해. 저장된 내용을 다시 화면에 표시하는 순서도 설명해.
