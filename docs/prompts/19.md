# 19. 예약 채팅방

## 기능 정리

프롬프트:
예약 상대와 채팅하는 화면을 만들어. 메시지를 주고받고 나중에 다시 읽는 기능으로 PRD 정리해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

기능별 화면 틀 만들기
프롬프트:
대화 내용은 시간순으로 놓고 아래에 메시지 입력칸과 전송 버튼을 넣어. 내가 보낸 말과 상대가 보낸 말을 구별해.

결과:
서로 관련 있는 내용과 버튼을 모았다.
사용한 파일: apps/web/src/pages/Shared.tsx:44 (Chat)

조회와 버튼 연결
프롬프트:
보낸 메시지를 저장하고 다시 들어와도 표시해. 전송을 다시 시도해도 같은 말풍선이 두 개 생기지 않게 해. 그 예약의 상대방만 대화에 들어오게 해.

결과:
재전송된 메시지를 구별해 중복 저장을 막도록 만들었다. 저장된 대화를 다시 읽어 말풍선 목록을 맞추도록 만들었다.
서버가 ID를 만들기 전에도 클라이언트의 같은 전송을 식별할 수 있어야 하도록 만들었다. 저장 재시도에 같은 키를 쓰고 다른 채팅에 재사용하지 않는다.
사용한 파일: apps/web/src/pages/Shared.tsx:44 (Chat)
