# 07. 면허 정보 입력

## 기능 정리

프롬프트:
운전면허 정보를 등록하는 화면을 만들어. 입력할 내용과 확인 상태를 PRD에 정리해.

결과:
입력할 내용, 버튼을 누른 뒤 바뀔 내용, 안내 문구를 PRD에 나눠 적었다.

## 단계별 프롬프트

동의와 입력 내용 처리
프롬프트:
면허 정보를 저장하고 다시 열면 저장된 내용을 표시해. 잘못 적은 항목은 알려주고, 입력만 한 상태와 확인이 끝난 상태는 구별해.

결과:
입력한 면허 정보를 확인하는 요청을 보내고 저장된 인증 목록을 다시 읽어 현재 상태를 보여주도록 만들었다.
번호를 입력했다는 사실만으로 실제 면허가 확인된 것은 아니다. 저장 정보·인증 상태·개발 모드를 나눠 보여주도록 만들었다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)
