# 16. 결제 수단 및 예약 요청

## 기능 정리

프롬프트:
결제수단을 고르고 예약을 요청하는 기능을 만들어. 요청을 보낸 것과 예약이 확정된 것은 나눠서 PRD에 적어.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

화면 흐름 만들기
프롬프트:
선택할 결제수단과 예약 금액을 보여주고 예약 요청 버튼을 넣어. 결제수단이 없으면 등록이 필요하다고 표시해.

결과:
내용을 보고 누르는 순서에 맞춰 화면을 배치했다.
사용한 파일: apps/web/src/pages/Guest.tsx:394 (Reservation)

실제 내용으로 바꾸기
프롬프트:
예약 요청이 한 번만 저장되게 해. 버튼을 다시 눌러도 같은 예약을 두 개 만들지 마. 요청이 들어가면 승인 대기라고 알려.

결과:
재전송된 예약 요청을 구별해 중복 생성을 막도록 만들었다. 예약 요청과 실제 승인·결제 완료를 나눠 표시하도록 만들었다.
시간초과 뒤 재시도도 같은 요청임을 서버에 알려야 하도록 만들었다. 같은 작업을 재시도할 때는 키를 유지하고 다른 요청에 같은 키를 재사용하지 않는다.
사용한 파일: apps/web/src/pages/Guest.tsx:394 (Reservation)

앞뒤로 이동하며 확인
프롬프트:
같은 예약을 다시 요청해도 중복되지 않는지 확인해. 금액이 바뀌었으면 다시 확인하게 하고, 승인 전에 결제된 것처럼 나오지 않게 고쳐.

결과:
관련 화면과 처리 코드를 확인하고 기존 검사 기록을 함께 정리했다.
