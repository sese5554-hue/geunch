# 31. 차량 외관 사진 등록

## 기능 정리

프롬프트:
차량 사진을 방향별로 등록하는 화면을 만들어. 사진을 올리고 바꾸는 기능으로 PRD 정리해.

결과:
차량 관리에 필요한 내용과 처리할 일, 막아야 할 변경을 PRD로 정리했다.

## 단계별 프롬프트

차량 관리 화면 만들기
프롬프트:
각 방향에 어떤 사진을 넣었는지 볼 수 있게 배치해. 아직 사진이 없는 곳과 올리는 중인 곳을 구별해.

결과:
관리할 항목과 현재 상태를 한 화면에 모았다.
사용한 파일: apps/web/src/pages/Host.tsx:494 (Photos)

처리 결과 남기기
프롬프트:
올린 사진을 차량에 저장하고 다시 열어도 표시해. 사진을 바꾸면 새 사진으로 보여주고, 실패한 사진은 다시 올릴 수 있게 해.

결과:
사진을 올린 뒤 방향별로 차량에 연결하도록 만들었다. 사진 교체와 실패 안내를 구별하고 저장한 사진을 다시 읽도록 연결했다.
파일을 일반 JSON 문자열로 바꾸면 파일 내용이 원하는 형식으로 전달되지 않는다. 파일 전송은 FormData를 사용하고 사진 연결은 ID로 처리하도록 만들었다.
사용한 파일: apps/web/src/pages/Host.tsx:494 (Photos)
