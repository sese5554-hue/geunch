# 04. 회원가입

## 기능 정리

프롬프트:
회원가입 화면을 만들어. 아이디, 비밀번호, 닉네임, 휴대폰 번호를 받고 약관 동의랑 휴대폰 확인도 필요해. 가입 순서를 PRD로 정리해.

결과:
입력할 내용, 버튼을 누른 뒤 바뀔 내용, 안내 문구를 PRD에 나눠 적었다.

## 단계별 프롬프트

칸과 버튼 배치
프롬프트:
가입에 필요한 입력칸과 아이디 중복 확인 버튼을 넣어. 빠뜨린 항목은 그 칸 가까이에 표시해.

결과:
선택하거나 입력하는 곳과 버튼을 배치했다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)

동의와 입력 내용 처리
프롬프트:
아이디 중복 확인이랑 휴대폰 확인이 끝나야 가입되게 해. 확인 후 아이디를 바꾸면 다시 중복 확인하게 하고, 가입할 때도 같은 아이디가 있는지 확인해.

결과:
가입 입력값과 동의·휴대폰 확인 여부를 검사하도록 만들었다. 저장할 때 아이디 중복을 다시 확인하고 비밀번호 원문은 저장하지 않게 했다.
입력한 비밀번호 원문을 DB에 저장하지 않도록 해시로 바꾼다. 로그인할 때는 verifyPassword로 입력과 저장된 해시를 비교하도록 만들었다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)

다시 들어와서 확인
프롬프트:
입력한 내용을 빼먹었을 때랑 이미 있는 아이디로 가입할 때를 확인해. 가입이 안 됐는데 완료 화면으로 넘어가는 부분이 있으면 고쳐.

결과:
관련 화면과 처리 코드를 확인하고 기존 검사 기록을 함께 정리했다.
