## 기능 정리

프롬프트:
차를 빌릴 사람인지, 자기 차를 빌려줄 사람인지 고르는 화면을 만들어. 두 가지 중 선택할 수 있게 PRD 정리해.

결과:
입력할 내용, 버튼을 누른 뒤 바뀔 내용, 안내 문구를 PRD에 나눠 적었다.

## 단계별 프롬프트

동의와 입력 내용 처리
프롬프트:
고른 쪽이 눈에 띄게 표시하고 선택한 내용도 저장해. 아무것도 안 골랐으면 먼저 고르라고 알려.

결과:
계정에 이용 유형을 추가하는 것과 지금 이용할 유형을 고르는 것을 나눠 처리하도록 만들었다. 바뀐 사용자 정보로 선택 표시를 갱신하도록 연결했다.
계정이 가진 역할 목록과 지금 사용하는 역할을 따로 보관하도록 만들었다. 화면 표시만 바꿔서는 서버 권한이 달라지지 않게 했다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)
