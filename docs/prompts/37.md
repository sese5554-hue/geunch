# 37. 게스트 마이페이지

## 기능 정리

프롬프트:
내 이름과 전화번호, 인증 상태를 한곳에서 보는 마이페이지를 만들어. 내 정보 화면에 필요한 내용을 PRD로 정리해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

조회와 버튼 연결
프롬프트:
내 정보를 불러오고 전화번호 가운데는 가려서 표시해. 정보를 바꾸고 돌아오면 최신 내용으로 표시해. 로그인 안 한 상태와 불러오기 실패는 구별해.

결과:
현재 사용자 정보와 별도로 조회한 자료를 맞춰 내 정보를 표시하도록 만들었다. 정보가 바뀌면 다시 읽거나 사용자 상태를 갱신하도록 연결했다.
직접 가지고 있는 사용자 정보와 useData로 받은 조회 자료가 다를 수 있다. 바뀐 자료가 어디에 있는지에 따라 사용자 상태 또는 재조회를 갱신하도록 연결했다.
사용한 파일: apps/web/src/pages/Shared.tsx:527 (Profile)
