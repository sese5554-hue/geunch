# 06. 동네 인증

## 기능 정리

프롬프트:
근차에서 '동네 인증' 부분을 만들어.
주소 고르고 현재 위치로 동네 확인하는 화면 만들어 위치 허용 안 했을 때 안내도 넣어.
이 내용으로 PRD 작성해. 화면에 나올 내용이랑 눌렀을 때 할 일을 정리해. 다른 담당 화면으로 넘어가는 건 나중에 연결해.
