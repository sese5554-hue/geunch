# 06. 동네 인증

## 기능 정리

프롬프트:
내가 사는 동네를 등록하고 확인하는 기능을 만들어. 주소를 고른 뒤 현재 위치로 확인하는 순서로 PRD 작성해.

결과:
입력할 내용, 버튼을 누른 뒤 바뀔 내용, 안내 문구를 PRD에 나눠 적었다.

## 단계별 프롬프트

칸과 버튼 배치
프롬프트:
주소를 검색해서 고르는 곳과 현재 위치를 확인하는 버튼을 넣어. 선택한 주소가 어디인지 화면에 표시해.

결과:
선택하거나 입력하는 곳과 버튼을 배치했다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)

동의와 입력 내용 처리
프롬프트:
고른 주소와 현재 위치로 동네 확인을 하고 결과를 저장해. 위치 사용을 거절하거나 위치를 못 가져오면 이유를 알리고 다시 시도하게 해.

결과:
선택한 주소와 기기에서 확인한 현재 위치를 나눠 사용하도록 연결했다. 위치 조회 거부와 시간초과를 안내하도록 만들었다.
고른 주소와 기기가 확인한 현재 좌표는 다른 값이다. NeighborhoodSearch와 currentPosition에서 이 값을 준비해 동네 검증에 사용하도록 연결했다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)
