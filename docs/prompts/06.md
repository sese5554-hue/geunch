# 06. 동네 인증

## 처음 부탁할 내용

나는 가입하고 로그인하는 쪽을 맡았어. 이번에는 '동네 인증' 화면을 만들려고 해.
아래 내용을 보고 PRD부터 써줘. 내가 빠뜨린 게 있으면 먼저 물어봐줘. 아직 코드는 만들지 말아줘.

이 화면에서 필요한 건 이거야.
- 검색한 주소랑 지금 위치를 확인할 수 있으면 좋겠어.
- 주소를 골라 동네를 확인하고 내 동네로 저장하고 싶어.
- 위치를 못 가져오면 멈추지 말고 권한을 확인하거나 다시 해보라고 알려주면 돼.

원래 있는 화면 모양이랑 공통으로 쓰는 부분은 그대로 써줘.
다른 담당 화면으로 넘어가는 연결은 나중에 같이 맞출게.

## 만들면서 부탁할 내용

어떤 순서로 만들지 정하기
바로 만들기 전에 어떤 순서로 하면 될지 먼저 알려줘. 내가 정해야 하는 부분도 따로 적어줘.
주소 고르고 현재 위치로 동네 확인하는 화면 만들어줘 위치 허용 안 했을 때 안내도 넣어줘.
만들 파일이랑 수정할 파일을 먼저 알려줘. 아직 코드는 만들지 말아줘.

화면 먼저 만들기
우선 화면부터 보고 싶어. 예시 내용으로 배치해주고, 입력하거나 선택한 게 눈에 보이게 해줘.
검색한 주소랑 지금 위치를 확인할 수 있으면 좋겠어.
일단 어떻게 보이는지 확인하고 다음으로 넘어가고 싶어.

화면에 들어갈 내용 정리하기
지금은 화면에만 있는 값인지 헷갈려. 내가 입력하는 내용과 나중에 다시 보여줄 내용을 나눠줘.
주소를 골라 동네를 확인하고 내 동네로 저장하고 싶어.
화면에 적힌 글자랑 실제로 바뀌는 내용을 나눠줘. 파일을 나누면 왜 나누는지도 설명해줘.

눌렀을 때 동작하게 하기
이제 누르면 실제로 저장되거나 처리되게 연결해줘. 성공한 경우와 실패한 경우를 구분해서 알려줘.
주소 고르고 현재 위치로 동네 확인하는 화면 만들어줘 위치 허용 안 했을 때 안내도 넣어줘.
위치를 못 가져오면 멈추지 말고 권한을 확인하거나 다시 해보라고 알려주면 돼.
처리 중에는 기다리는 표시를 보여줘. 실패했는데 완료됐다고 나오면 안 돼.

직접 확인하고 마무리하기
가입하는 사람이 처음 써본다고 생각하고 확인할 순서를 알려줘. 내가 하나씩 눌러볼게.
처음 적은 PRD랑 비교해서 빠진 기능이 있는지도 봐줘.
잘 되는 경우랑 안 되는 경우를 나눠서 확인하고, 다른 담당자랑 합칠 때 맞춰야 할 것도 알려줘.

## 잘 안 되거나 설명이 어려울 때

추가로 물어볼 말
주소는 골랐는데 동네 확인이 안 돼. 위치 허용도 눌렀는데?
지금 코드에서 이 경우가 생길 수 있는지 확인해줘. 고쳐야 하면 어디를 바꾸는지랑 이유도 알려줘.

내가 고른 주소랑 지금 있는 곳은 다를 수도 있잖아. 뭘 보고 확인하는 거야?
이 화면을 예로 들어서 쉬운 말로 설명해줘.
