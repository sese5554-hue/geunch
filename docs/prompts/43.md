# 43. 1:1 문의 접수

## 처음 부탁할 내용

나는 같이 쓰는 기능을 맡았고, 이번에는 '1:1 문의 접수'을 하려고 해.
아래 기능으로 PRD를 정리해줘. 누가 볼 수 있는지, 처리한 뒤 무엇이 달라지는지도 넣어줘.

이 화면에서 필요한 건 이거야.
- 문의 종류, 제목, 내용을 적고 사진도 붙일 수 있으면 돼.
- 접수를 누르면 한 번만 저장되고 접수됐는지 알려주면 좋겠어.
- 제목이 없거나 사진 올리기 실패면 적은 내용은 남겨두고 다시 할 수 있으면 돼.

원래 있는 화면 모양이랑 공통으로 쓰는 부분은 그대로 써줘.
다른 담당 화면으로 넘어가는 연결은 나중에 같이 맞출게.

## 만들면서 부탁할 내용

어떤 순서로 만들지 정하기
이 화면을 쓰는 사람이 누구인지부터 정리해줘. 앞뒤 기능이 필요한 부분은 내가 맡은 범위랑 나눠서 알려줘.
문의 제목 내용 적고 사진 붙여서 접수되게 해줘 실패해도 적은 내용은 남겨줘.
만들 파일이랑 수정할 파일을 먼저 알려줘. 아직 코드는 만들지 말아줘.

화면 먼저 만들기
우선 예시 내용으로 화면을 보여줘. 처리 전이랑 처리 후에 무엇이 달라지는지도 볼 수 있으면 좋겠어.
문의 종류, 제목, 내용을 적고 사진도 붙일 수 있으면 돼.
일단 어떻게 보이는지 확인하고 다음으로 넘어가고 싶어.

화면에 들어갈 내용 정리하기
화면을 닫아도 남아야 하는 내용과 잠깐 선택하는 내용을 나눠줘. 다른 사람 내용이 보이지 않게 해줘.
접수를 누르면 한 번만 저장되고 접수됐는지 알려주면 좋겠어.
화면에 적힌 글자랑 실제로 바뀌는 내용을 나눠줘. 파일을 나누면 왜 나누는지도 설명해줘.

눌렀을 때 동작하게 하기
이제 누르면 실제로 저장되거나 처리되게 연결해줘. 성공한 경우와 실패한 경우를 구분해서 알려줘.
문의 제목 내용 적고 사진 붙여서 접수되게 해줘 실패해도 적은 내용은 남겨줘.
제목이 없거나 사진 올리기 실패면 적은 내용은 남겨두고 다시 할 수 있으면 돼.
처리 중에는 기다리는 표시를 보여줘. 실패했는데 완료됐다고 나오면 안 돼.

직접 확인하고 마무리하기
한 번 처리한 다음 다시 들어와서 확인해볼게. 비어 있을 때랑 상대방 확인이 필요한 경우도 확인 목록에 넣어줘.
처음 적은 PRD랑 비교해서 빠진 기능이 있는지도 봐줘.
잘 되는 경우랑 안 되는 경우를 나눠서 확인하고, 다른 담당자랑 합칠 때 맞춰야 할 것도 알려줘.

## 잘 안 되거나 설명이 어려울 때

추가로 물어볼 말
문의 보내기 실패했더니 적었던 내용까지 없어졌어.
지금 코드에서 이 경우가 생길 수 있는지 확인해줘. 고쳐야 하면 어디를 바꾸는지랑 이유도 알려줘.

사진은 올렸는데 문의 보낼 땐 왜 사진 대신 번호 같은 걸 보내?
이 화면을 예로 들어서 쉬운 말로 설명해줘.
