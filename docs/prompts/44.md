# 44. 채팅 목록

## 기능 정리

프롬프트:
내가 주고받은 채팅 목록을 만들어. 상대와 마지막 메시지, 안 읽은 내용을 구별하는 내용으로 PRD 정리해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

조회와 버튼 연결
프롬프트:
새 메시지가 오거나 대화를 읽고 돌아오면 마지막 내용과 안 읽은 개수를 바꿔. 내 대화만 표시하고, 대화가 없으면 없다고 알려.

결과:
내 대화 목록의 마지막 메시지와 읽지 않은 개수를 조회하도록 연결했다. 메시지와 읽음 변경을 목록에 반영하도록 연결했다.
메시지의 순서를 기준으로 마지막 읽은 위치를 정확히 지정할 수 있다. 읽음 위치가 이전 값으로 되돌아가지 않도록 갱신하도록 연결했다.
사용한 파일: apps/web/src/pages/Shared.tsx:1003 (Conversations)
