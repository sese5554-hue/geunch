## 기능 정리

프롬프트:
예약 요청을 보낸 뒤 결과를 보여주는 화면을 만들어. 대기 중인지 확정됐는지 알 수 있게 PRD 써.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

실제 내용으로 바꾸기
프롬프트:
예약의 현재 상태를 읽어서 안내를 바꿔. 요청만 보낸 상태를 확정이라고 표시하지 말고, 승인이 필요한 상태면 대기 중이라고 알려.

결과:
예약의 현재 상태를 읽어 접수·승인 대기·확정을 구별하도록 만들었다. 요청을 보냈다는 이유만으로 확정 문구를 띄우지 않게 했다.
요청 접수와 최종 확정은 다른 상태다. 현재 흐름은 호스트 승인과 결제를 거쳐 확정으로 진행하도록 만들었다.
사용한 파일: apps/web/src/pages/BookingDetail.tsx:24 (BookingDetail)
