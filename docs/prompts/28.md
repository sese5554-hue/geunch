# 28. 차량 기본 정보 입력

## 기능 정리

프롬프트:
차 이름, 연식, 차량번호, 동네부터 입력해서 저장하는 화면을 만들어. 나머지 등록은 나중에 이어 하는 내용으로 PRD 정리해.

결과:
차량 관리에 필요한 내용과 처리할 일, 막아야 할 변경을 PRD로 정리했다.

## 단계별 프롬프트

차량 관리 화면 만들기
프롬프트:
기본 정보를 위에서부터 입력하게 배치하고 저장 버튼을 넣어. 이 단계에서는 아직 공개되지 않는다는 안내도 표시해.

결과:
관리할 항목과 현재 상태를 한 화면에 모았다.
사용한 파일: apps/web/src/pages/Host.tsx:201 (BasicForm)

처리 결과 남기기
프롬프트:
기본 정보를 저장하고 다시 열어도 같은 내용이 나오게 해. 빠뜨린 항목이나 중복 차량번호는 알려. 저장만 했다고 검색에 공개하지 마.

결과:
차량 기본 정보를 공개 전 초안으로 저장하도록 연결했다. 필수 입력과 차량번호 중복을 확인하며 저장만으로 검색에 공개하지 않게 했다.
저장된 초안이라는 뜻이다. 아직 빌릴 수 있게 공개된 상태가 아니라서 검색 노출과 구별하도록 만들었다.
사용한 파일: apps/web/src/pages/Host.tsx:201 (BasicForm)
