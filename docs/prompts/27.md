결과:

## 단계별 프롬프트

차량 관리 화면 만들기
프롬프트:
현재 저장된 차량 내용을 먼저 채워서 표시해. 수정할 곳과 숨김, 삭제 버튼을 구별해.

결과:
관리할 항목과 현재 상태를 한 화면에 모았다.
사용한 파일: apps/web/src/pages/Host.tsx:254 (VehicleEdit)

처리 결과 남기기
프롬프트:
바꾼 내용을 저장하고 다시 열면 수정한 값으로 표시해. 예약 때문에 지울 수 없는 차는 이유를 알리고 막아. 다른 창에서 먼저 수정했으면 덮어쓰지 말고 다시 확인하게 해.

결과:
내 차량인지 확인하고 저장된 수정 번호를 비교하도록 만들었다. 다른 창의 수정 내용을 무조건 덮지 않고 기존 예약에 따른 삭제 조건도 확인하도록 만들었다.
다른 창에서 저장한 내용을 모르게 지울 수 있다. 충돌을 안내하고 최신 값에서 다시 수정하도록 하도록 만들었다.
사용한 파일: apps/web/src/pages/Host.tsx:254 (VehicleEdit)
