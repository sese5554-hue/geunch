# 13. 차량 세부 정보

## 기능 정리

차 좌석 수, 연료, 옵션 같은 세부 정보를 모아서 보고 싶다.
선택한 차의 정보가 맞게 나오고 읽기 편하면 된다.
비어 있는 정보는 없는 내용까지 있는 것처럼 보여주지 않았으면 좋겠다.

## 단계별 프롬프트

실제 내용으로 바꾸기
프롬프트:
차의 좌석 수, 연료, 옵션을 한곳에 모아서 표시해. 선택한 차의 정보가 나오게 하고, 등록하지 않은 내용은 정보가 없다고 표시해.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.
선택한 차량의 좌석·연료·옵션 값을 읽어 보여주도록 만들었다. 등록하지 않은 정보와 불러오기 실패를 구별하도록 만들었다.
Vehicle 타입은 응답 데이터의 형태를 설명하도록 만들었다. 컴포넌트는 그 객체의 좌석·연료·옵션 값을 읽어 표시하도록 만들었다.
사용한 파일: apps/web/src/pages/Guest.tsx:289 (VehicleDetail)
