## 단계별 프롬프트

조회와 버튼 연결
프롬프트:
이름을 수정해 저장하고, 휴대폰은 새 번호 확인을 마쳐야 바뀌게 해. 번호 확인에 실패하면 기존 번호는 그대로 남겨.

결과:
일반 정보 수정과 휴대폰 번호 변경을 나눠 처리하도록 만들었다. 새 번호 확인을 마쳐야 번호 변경을 저장하도록 연결했다.
본인 소유가 아닌 번호로 변경하는 것을 막아야 하도록 만들었다. 검증된 새 번호인지 확인한 뒤에만 바꾼다.
