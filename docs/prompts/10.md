# 10. 차량 검색 결과

## 기능 정리

프롬프트:
차 검색 결과 화면을 만들어. 내가 고른 조건과 차 목록을 같이 보고 정렬도 바꿀 수 있게 PRD 정리해.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

실제 내용으로 바꾸기
프롬프트:
정렬을 바꾸거나 다음 목록으로 넘어가도 검색 조건은 그대로 둬. 새로고침해도 같은 조건으로 찾고, 결과가 없으면 없다고 표시해.

결과:
검색 조건을 주소에 남기고 그 값으로 차량을 찾도록 연결했다. 새로고침하거나 정렬을 바꿔도 적용된 조건을 이어서 사용하도록 연결했다.
같은 조건으로 다시 열거나 새로고침할 수 있게 하도록 만들었다. 화면의 선택값과 서버에 보내는 조건도 같은 값을 사용하도록 연결했다.
