## 단계별 프롬프트

실제 내용으로 바꾸기
프롬프트:
적용을 누르면 고른 조건으로 차를 찾아. 초기화하면 선택한 조건도 같이 지워. 최소 가격이 최대 가격보다 크면 다시 확인하게 해.

결과:
조건을 고르는 값과 현재 적용된 조건을 나눠 다루도록 정리했다. 초기화할 때 입력 내용과 검색에 쓸 조건을 함께 정리하도록 만들었다.
필터에서 편집 중인 값과 적용된 검색 조건이 나뉠 수 있다. 적용·초기화 때 어떤 값을 요청에 쓰는지 맞춰야 하도록 만들었다.
