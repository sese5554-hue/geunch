# 26. 호스트 차량 목록

## 기능 정리

프롬프트:
내가 등록한 차량을 모아서 보는 목록을 만들어. 공개 중인 차와 등록 중인 차를 구별하는 내용으로 PRD 작성해.

결과:
차량 관리에 필요한 내용과 처리할 일, 막아야 할 변경을 PRD로 정리했다.

## 단계별 프롬프트

처리 결과 남기기
프롬프트:
내 차만 목록에 나오게 해. 저장한 내용과 공개 상태를 같이 표시하고, 등록한 차가 없으면 차량 등록 안내를 넣어.

결과:
로그인한 호스트의 차량만 목록으로 읽도록 연결했다. 공개 상태를 구분해 보여주고 등록된 차가 없는 경우를 안내하도록 만들었다.
서버가 세션에서 현재 사용자를 알아낸다. 클라이언트가 보내는 소유자 ID를 믿고 차량 목록을 만들지 않는다.
