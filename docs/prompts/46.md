기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

기능별 화면 틀 만들기
프롬프트:
등록에 필요한 입력칸과 추가 버튼을 넣어. 지금은 개발용 등록이라는 안내도 표시해.

결과:

조회와 버튼 연결
프롬프트:
등록한 결제수단이 내 목록에 나오게 해. 같은 등록을 두 번 하지 못하게 하고, 카드번호를 앱에 그대로 남겨두지 마.

결과:
카드 원문 대신 등록 처리에 필요한 참조값으로 결제수단을 추가하도록 만들었다. 개발용 등록을 구별하고 같은 등록의 중복을 확인하도록 만들었다.
사용자·유효시간과 연결된 등록 작업을 식별하기 위해서다. 현재는 실제 카드사 대신 개발 공급자를 사용하도록 연결했다.
사용한 파일: apps/web/src/pages/Shared.tsx:770 (AddPayment)
