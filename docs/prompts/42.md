# 42. 고객센터

## 기능 정리

자주 묻는 질문이랑 답을 찾아볼 수 있으면 좋겠다.
궁금한 항목의 내용을 읽을 수 있으면 된다.
아무 항목도 못 읽었으면 잠시 후 다시 보라고 안내하고 싶다.

## 단계별 프롬프트

조회와 버튼 연결
프롬프트:
고객센터에서 자주 묻는 질문과 답변을 볼 수 있게 만들어. 질문을 누르면 답이 펼쳐지게 하고, 내용을 못 불러오면 다시 볼 수 있게 해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.
자주 묻는 질문과 답을 조회해 펼쳐 읽을 수 있게 만들었다. 비어 있는 내용과 불러오기 실패를 안내하도록 만들었다.
현재 FAQ는 계정 라우트의 정해진 질문 목록을 응답하도록 만들었다. 모든 조회 화면이 DB 테이블을 새로 요구하는 것은 아니다.
