# 20. 인수 전 차량 상태

## 기능 정리

프롬프트:
차를 받기 전에 사진과 주행거리를 남기는 인수 화면을 만들어. 잠깐 저장하는 것과 인수를 마치는 것을 PRD에서 구별해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

기능별 화면 틀 만들기
프롬프트:
방향별 사진을 넣는 곳과 계기판 사진, 주행거리 입력칸을 만들어. 아직 안 올린 사진은 무엇인지 표시해.

결과:
서로 관련 있는 내용과 버튼을 모았다.
사용한 파일: apps/web/src/pages/Shared.tsx:183 (Inspection), apps/web/src/pages/Shared.tsx:216 (InspectionForm)

조회와 버튼 연결
프롬프트:
사진과 주행거리를 저장해. 임시 저장만 했을 때는 인수 완료로 바꾸지 말고, 필요한 내용을 다 넣은 뒤 인수를 마치게 해.

결과:
사진을 잠깐 보관하는 것과 인수 완료 제출을 나눠 처리하도록 만들었다. 최종 인수는 시작 30분 전부터 허용하고 필요한 조건을 확인하도록 만들었다.
사진을 잠깐 저장하는 것과 인수를 확정하는 것을 구분하도록 만들었다. 최종 제출 조건이 맞을 때만 예약 상태를 IN_USE로 바꾼다.
사용한 파일: apps/web/src/pages/Shared.tsx:183 (Inspection), apps/web/src/pages/Shared.tsx:216 (InspectionForm)

계정과 결과 확인
프롬프트:
예약 시작 30분 전부터 인수를 마칠 수 있는지 확인해. 사진이나 주행거리가 빠졌는데 완료되는 부분은 막아.

결과:
관련 화면과 처리 코드를 확인하고 기존 검사 기록을 함께 정리했다.
