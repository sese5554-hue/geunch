# 22. 외관 및 계기판 비교

## 기능 정리

프롬프트:
차를 받을 때와 돌려줄 때의 상태를 비교하는 화면을 만들어. 양쪽이 확인하는 순서로 PRD 정리해.

결과:
기능을 쓰는 사람, 보여줄 내용, 버튼 동작과 안내 문구를 PRD에 묶었다.

## 단계별 프롬프트

기능별 화면 틀 만들기
프롬프트:
인수 사진과 반납 사진을 비교해서 볼 수 있게 배치해. 나와 상대방이 확인했는지도 따로 표시해.

결과:
서로 관련 있는 내용과 버튼을 모았다.
사용한 파일: apps/web/src/pages/Shared.tsx:301 (Comparison)

조회와 버튼 연결
프롬프트:
확인 버튼을 누른 사람의 결과를 저장해. 이의가 있으면 그 내용도 남기고, 양쪽 확인이 끝나야 정산으로 넘어가게 해.

결과:
나와 상대방의 확인 여부를 따로 읽도록 연결했다. 양쪽 확인과 이의 상태에 따라 정산을 진행할 수 있는지 판단하도록 만들었다.
두 사람이 같은 예약을 확인해야 하기 때문이다. 예약 하나의 확인 여부만 저장하면 누가 확인했는지 알 수 없다.
사용한 파일: apps/web/src/pages/Shared.tsx:301 (Comparison)

계정과 결과 확인
프롬프트:
한쪽만 확인했거나 이의가 남아 있을 때 정산이 끝나지 않는지 확인해. 다시 들어와도 누가 확인했는지 맞게 표시해.

결과:
관련 화면과 처리 코드를 확인하고 기존 검사 기록을 함께 정리했다.
