# 08. 게스트 홈

## 기능 정리

프롬프트:
게스트 홈에서 내 동네와 빌릴 수 있는 차를 같이 볼 수 있게 만들어. 동네를 바꿔서 찾는 흐름으로 PRD 정리해.

결과:
사용자가 이 화면에서 보고 고르는 내용을 이용 순서에 맞춰 PRD로 정리했다.

## 단계별 프롬프트

실제 내용으로 바꾸기
프롬프트:
동네를 바꾸면 그 동네 차 목록으로 바꿔. 동네를 아직 안 정했으면 먼저 정하게 하고, 차가 없는 것과 목록을 못 불러온 것은 다르게 안내해.

결과:
선택한 동네와 조건으로 차량을 다시 찾도록 연결했다. 이전 요청이 늦게 돌아와도 현재 목록을 덮지 않게 처리하도록 만들었다.
서버는 화면에서 무엇을 선택했는지 자동으로 알지 못하도록 만들었다. 선택한 조건을 요청에 넣고 응답 목록을 화면 상태에 반영하도록 연결했다.
