# 03. 로그인

## 기능 정리

프롬프트:
아이디와 비밀번호로 로그인하는 기능을 만들어. 틀렸을 때 안내하는 것까지 넣어서 PRD 써.

결과:
입력할 내용, 버튼을 누른 뒤 바뀔 내용, 안내 문구를 PRD에 나눠 적었다.

## 단계별 프롬프트

칸과 버튼 배치
프롬프트:
아이디, 비밀번호 입력칸이랑 로그인 버튼을 배치해. 잘못 입력했다는 안내는 버튼 근처에 표시해.

결과:
선택하거나 입력하는 곳과 버튼을 배치했다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)

동의와 입력 내용 처리
프롬프트:
로그인 버튼을 누르면 입력한 내용으로 로그인해. 틀리면 화면을 넘기지 말고 다시 적게 해. 새로고침해도 로그인은 유지해.

결과:
아이디와 비밀번호를 확인한 뒤 로그인 상태를 보관하도록 만들었다. 새로고침할 때 현재 사용자를 다시 확인해 화면에 표시하도록 만들었다.
다음 요청과 새로고침 뒤에도 같은 사용자임을 서버가 확인하도록 했다. 쿠키의 토큰을 서버 세션과 대조하고 사용자 정보를 돌려준다.
사용한 파일: apps/web/src/pages/Auth.tsx:17 (AuthPage)
