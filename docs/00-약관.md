## 확인한 내용

- 전체 동의 후 하나를 풀면 전체 동의 표시도 풀린다.
- 필수 항목만 체크해도 저장할 수 있다.
- 선택 항목을 거부한 값도 그대로 저장된다.
- 저장 후 새로고침해도 같은 내용이 나온다.
- 저장 실패 때 완료 안내나 동의 쿠키를 만들지 않는다.
- 실패 후 선택값을 유지하고 다시 저장할 수 있다.
- 이전 버전, 잘못된 입력, 다른 사이트의 저장 요청을 거절한다.
- 실제 MariaDB에 저장하고, 연결을 종료한 뒤 새 서버·연결에서 다시 읽었다.
